# Location Plan

Branch `location-plan` (off `stockpile-prices`, 2026-11-07, Jan): a player marks what a location should produce or have,
and sees on the map which locations are done. Only visual and only for the player; nothing is built by it. The
automatic Construction Plan (branch `player-construction-manager`) is parked; this is the simpler first step of planning.

## In game

- **Plan button** in the header of the location window (player-owned locations, not observers), left of the go-to arrow.
  It opens the **Location Plan** window on that location.
- **Window:** the location's planned items (green once done, red while still to do, "N of M done"), and a picker:
  every good (grouped Farming, Forestry, Gathering, Hunting, Manufactured, Mining) and eight building categories (Trade,
  Government, Military, Defensive, Religious, Cultural, Naval, Infrastructure). Click an icon to plan or unplan it;
  planned icons carry a gold frame. Clear empties the plan.
- **Map mode Location Plan** (economy group, or "Show on map" in the window): each planned item as an icon over the
  location, on a green tile once done, red while still to do; hover an icon for its name and state. The map underneath
  is the raw material map faded almost out. Test build (2026-11-07): only lumber and furniture draw icons
  (`marker_items`); every item still works in the window.

A planned good is done once the location produces it: its raw material is that good, or a standing building there
produces it (`building_produced_goods`). A building category is done once a building of it stands there.

## Code

- Generated by `location_plan.py` at finalize (`[location_plan]` in `constructor.toml`: categories, hidden goods, icons
  per row): done values and counts, the toggle switch, the picker grid and planned strip, the item texts and the
  patched `gui/map_markers.gui` (see Map icons). It also patches the plan button into the location window (`location_view.build_window`).
- Hand-written: `scripted_effects/pp_location_plan.txt` (flip with count, select), `scripted_guis/pp_location_plan.txt`,
  `gui/pp_location_plan.gui` (window, scripted widget), `gfx/map/map_modes/pp_location_plan_map_mode.txt`, the game
  concept and icon (copy of vanilla `building_based`), `pp_location_plan_l_english.yml`.
- Location variables `pp_lplan_g_<good>` / `pp_lplan_c_<category>` (present = planned), `pp_lplan_n` (items + 100);
  country `pp_lplan_sel` (the location the window shows).
- Tests: `tests/test_location_plan.py`.

## Map icons

The icons are vanilla's raw goods marker. `location_plan.py` copies vanilla `gui/map_markers.gui` into the mod and
splits only the `raw_goods_marker` widget (a test checks the rest is vanilla): outside the plan map mode it shows
vanilla's raw goods icon, in it a row of the planned `marker_items` icons, for player-owned locations only.

Engine facts (in game 2026-11-07):
- The engine creates raw goods markers only with `color_mode = raw_material`. `map_markers = { raw_goods_marker = yes }`
  alone shows none (vanilla's market_food_balance neither), raw_material map names do not create them.
- With a `color_mode`, `map_color` and `tooltip_key` are ignored (error.log says so). So no map coloring and no
  location hover text in this mode; the icons carry their own tooltips. Gradient alpha 0.12 fades the raw colors.
- Map marker types are fixed by the engine and loaded only from `map_markers.gui`, `map_markers_city.gui`,
  `map_markers_construction.gui`; map name text cannot draw icons.
- The marker hides at the farthest zoom (vanilla's zoom range) and covers the location name. Icon size scales with zoom,
  capped at 60.
- Mods that override `map_markers.gui` win if they load after PP: in Jan's playset Faster Universalis (3662193478),
  3601047146 and 3735059838 do. PP must load after them for the icons.
- `refresh_map_colors = yes` after a toggle redraws the markers at once.
- GUI and map mode files hot-reload in a running game; loc and script files do not.

Tested 2026-11-07 in a new game as England (saves `pp_lplan_england`, `pp_lplan_icons_england`): window, picker, strip,
counts; map icons (Woking and Guildford lumber + furniture, Shoreham lumber on green from its lumber RGO, the rest red),
icon tooltips, vanilla Raw Materials map mode unchanged; no plan lines in error.log.
