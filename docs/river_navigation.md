# River navigation integration

The geography producer is EU5WorldBuilder, `configs/river_navigation.json`. Constructor consumes its checked, versioned `navigation/` handover and compiles buildings, road types, startup routes and original river-bank effects. Gameplay settings are in `config/river_navigation.json`.

## Building and updating

In World Builder run `uv run worldbuilder navigation`, `uv run worldbuilder geography-test --build-only --export-only`, and `uv run worldbuilder handover`. Then run `uv run ppc build`, `uv run ppc worldbuilder check`, `uv run ppc blueprint parity`, and `uv run ppc test`. `uv run ppc sync --yes` deploys to the machine-local configured live target; it requires user authorization.

A complete game restart and a **new campaign** are required. Existing saves do not have the new location identities or startup routes. The production mod includes the World Builder geography; do not stack its standalone geography mod or the unrelated downloaded navigable-rivers mod on top.

## Gameplay

* Navigable reaches use a moderate movement and market-access reduction.
* Improvable reaches remain passable but expensive until the assigned bank location completes works.
* Permanent barriers are sea zones also listed as impassable ocean wasteland. The user verified this mechanism blocks fleets in the Thames prototype.
* Improved connections are generated by the building completion hook. A destruction hook restores baseline road types; engine acceptance of downgrading an existing higher-level road still needs an in-game check.
* Roads cannot be built from the normal road menu. Only startup and the assigned building hooks create them.
* The engine applies sea movement to every fleet class. There is no claimed small-boat restriction or verified one-way road behavior. Army crossings did not respond to road movement in the user test.

Six expensive works types reuse existing capacity families: River Navigation Works, Canal Lock Works, Caoyun Canal Offices, Lowland Sluice Works, Nile Navigation Works and Delta Waterway Works. Only eligible mapped bank sites can construct them; each site allows one level. General and Nile works share irrigation capacity; Caoyun and delta works share irrigated-field capacity; Lowland Sluice Works share polder capacity. At a full allowance the player must remove one existing level from that family first. Startup replaces up to one general family level with equal-capacity navigation works in supported historical regions. It never awards a free additional level. Existing Jiangnan Canal Networks also activate their assigned navigation connections; they retain their stronger regional capacity and their construction price is raised to reflect the expanded role. Costs, maintenance, construction time, regional bounds and historical-placement evidence are configurable.

Historical placement is regional inference, not a claim that each individual game location had that exact institution in 1300. The Grand Canal evidence is strongest; the Nile is a long-lived navigation/irrigation-system proxy, and Delfland uses the documented medieval water-board area. Britain receives future investment opportunities, not its much later eighteenth-century canal network at game start.

## Preserving river banks

The original maximum native river level is preserved in `rivers.png` itself. Converted channels are removed from that bitmap; if a land bank loses its original maximum level, an existing ordinary pixel is resized or a minimal source-and-size segment is retained beside its former channel. This follows the user's bank-pixel suggestion. It preserves the engine's normal river modifier, `has_river`, native building requirements and fishing-capacity modifier rather than trying to emulate them with several scripted bonuses. The previous positive/negative compensation modifiers and original-level markers are no longer applied. The existing river proximity graph is not reconstructed by these minimal bank segments.

The prior engine export found exactly one active size modifier per river location. The old preservation implementation incorrectly treated every palette size occurring in a location as a separate active modifier. The new raster audit compares the largest size before and after, prevents transferred bank fragments from promoting the recipient's level, repairs source/tributary topology on cut fragments, and checks that no native river pixels remain on converted water. The pixel rule is validated against the existing marker-aware river-size model and the strict native river-forest validator; recognition of newly minimal bank segments still requires a fresh in-game verification. The map mode reads actual native modifiers, so an unrecognized bank pixel will not be hidden by a scripted imitation.

Every new river port has an audited coordinate on adjacent passable water and a dock locator. Geography templates receive a configurable natural-harbor floor (existing higher values are retained). Vanilla port buildings use `is_port`; no dock building is required to define the map port. Original valid ports are preserved because the engine supports one port per location. Native river-mouth harbor bonuses may now apply to newly coastal river banks, in addition to their preserved normal river level.

Small riverbank raster fragments may move to an adjoining bank within strict configured size/area limits. Larger banks retain the original location identity on both sides. All original land locations remain and lost adjacencies between different locations receive explicit crossings. Location bisections and all omissions are reported; the global map still needs in-game validation beyond the successful local prototype.

Conservative land-area/crossing guards can still leave native river stretches and inland components; the map mode explicitly identifies water tiles without an open-sea connection.

Open **Geography → Rivers and Navigation**. Land colours show the actual native river level. Water colours show open, unimproved, difficult, barrier or maintained state. Hover for original river level, open-sea connectivity and port status. Maintained and partly maintained states query the actual road types on adjacent connections; they do not assume that a demolition hook successfully downgraded a road. Inspect individual connections for precise costs where different sites meet. Colours refresh with road changes and the daily refresh counter. The same fleet can be tested through London, Windsor and Abingdon; compare fishing capacity and river-only building eligibility on the banks before examining movement. Rotterdam, the Jiangnan canal area and the Nile remain useful regional works checks. Start a fresh campaign after restarting the game.

### Tropical and seasonal navigation

Latitude is a configurable coarse screening policy, not a claim that jungle makes rivers unnavigable. Within the tropical band, the default mean/low-flow thresholds are stricter, leaving smaller and strongly seasonal tributaries as native rivers. Selected tropical or strongly seasonal routes receive the difficult cost profile; navigation works can improve their maintained connections. Physical gradient screening and explicit falls remain independent of this rule.

The [Mekong River Commission](https://archive.iwlearn.net/mrcmekong.org/RAK/html/1.15.3_river_navigation.html) identifies Khone Falls as a complete barrier and describes vessel restrictions from rapids and shoals. Khone now has an explicit barrier envelope. The [World Bank Congo transport study](https://documents1.worldbank.org/curated/en/684111495448714514/pdf/WP-TradeFacilitationEnglishmainweb-PUBLIC.pdf) documents an extensive navigable basin network alongside restrictions. Brazil's [DNIT Solimões description](https://www.gov.br/dnit/pt-br/assuntos/aquaviario/antiga-daq/hidrovia-do-solimoes) supports keeping the major Amazon–Solimões corridor physically navigable far inland. These sources support natural capability and obstacles; modern dredging, aids and fleet capability are not evidence for medieval infrastructure. Regional costs and threshold numbers are balance approximations, not measured 1300 transport prices.

Six original building icons were generated with the built-in image_gen tool and saved under `blueprints/accepted/assets/icons/`. Exact paths and prompts are recorded in [river_navigation_icon_prompts.json](river_navigation_icon_prompts.json).
