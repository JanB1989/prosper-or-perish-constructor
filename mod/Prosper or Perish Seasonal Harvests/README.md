# Seasonal Harvests

This standalone mod adds the yearly regional harvest effects from Prosper or Perish. Each September, harvest conditions are rolled across broad harvest areas and affect goods output in owned locations. Average harvests leave no modifier. The campaign game rule can disable the system.

It does not include the Prosper or Perish food, buildings, population, or balance overhaul.

## Install

Place the `Prosper or Perish Seasonal Harvests` folder in your Europa Universalis V `mod` folder, then enable **Seasonal Harvests** in the launcher. The standalone mod does not require Prosper or Perish.

## Version

1.1.0 — compatible with EU5 1.4. Built from the Prosper or Perish harvest files, so the two mods can be loaded together: the files and texts of the same name replace each other and nothing loads twice.
