# Schools (literacy rework 2026-11-25, Jan; hand-written): three advances inside institution trees, so only countries
# that embraced the institution can research them. Each hangs directly under the institution's root advance, which
# carries the institution gate (vanilla's pattern for every advance of an institution tree).
# The AI's advance picker ignores research cost and puts no value on what these give (class literacy caps, a building
# level), so each carries an ai_weight like the writing branch of the Starting Technology Ladder
# (config/starting_technology.toml [ai_weight]).
# Icons: assets/icon_drawings/<advance>/draw.py, installed by tools/build_school_icons.py.
