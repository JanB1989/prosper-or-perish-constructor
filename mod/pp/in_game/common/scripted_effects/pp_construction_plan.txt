# Prosper or Perish - Construction Plan (branch player-construction-manager, 2026-11-06, Jan; two tabs since 2026-11-09,
# a third and a sixth rule group since 2026-11-10).
# Player-only construction rules, run once a month by on_action/pp_construction_plan.txt for each human country that
# switched the plan on. Global settings: a gold reserve and six rule groups (Locations = the location profiles and the
# Location Plan's marks, Food per province, Logistics per location, Improvements per location, Businesses, Towns and
# Buildings), each with a weight (its part of the new gold above the reserve = its weight over the sum of the weights
# that count; 0 = off; Locations and Towns and Buildings count only while they have something to do) and a budget
# that saves (its purse, since 2026-11-10; "Budgets that save" below); Logistics,
# Improvements and Businesses with a line, Towns and Buildings with a tab of its own (construction_plan_country.py:
# pp_cplan_group_country, pp_cplan_country_rights). The per-location layer (pp_location_profiles.txt): a location's
# profile takes from the rule groups only what it sets (its rules' targets and the groups it switches off;
# pp_cplan_*_ok in scripted_triggers), the rest still build in its locations; a location's marks ("Also build here")
# add to them and switch nothing off. The pickers per
# building, the profit estimates and the build cost data are generated from [construction_plan] into
# pp_construction_plan_generated.txt (construction_plan.py). Constructions are normal, paid constructions
# (construct_building), so they show in the construction queue like the player's own.
# Variables carry + 100 (a variable at 0 counts as unset; var:x = n compares scopes, so only < / > ranges are used).
#
# Country variables: pp_cplan_on (the plan runs), pp_cplan_w_profiles / _food / _logistics / _improve / _business /
# _country (the rule groups' weights), pp_cplan_reserve / _access / _imp / _biz (the window's lines; defaults in
# [construction_plan]),
# the list pp_cplan_log (locations built in by the last pass), the last pass's pp_cplan_started / _spent, and during a
# pass only: pp_cplan_hit, pp_cplan_noted, pp_cplan_wait, pp_cplan_mlim, pp_cplan_bz_<type> (the business types the
# country can build), the list pp_cplan_markets (markets whose constructions the market limit counted).
# Budgets that save (Jan 2026-11-10; the state the rules keep from pass to pass, per rule group <why>, + 100):
# pp_cplan_purse_<why> (the gold the group has saved), pp_cplan_in_<why> (what it received for this pass),
# pp_cplan_hand_<why> (what was handed on to it at the end of the last pass), and what it saves for: pp_cplan_save_cost_
# <why> (set = it saves; the cost), pp_cplan_save_loc_<why> (the location), pp_cplan_save_type_<why> (the building
# type) or pp_cplan_save_rank_<why> (101 a town, 102 a city upgrade). Generated: pp_cplan_purses_fill /
# pp_cplan_purses_hand_on and the values pp_cplan_purse_* (construction_plan.py render_purse_values).
# What the window's detail panes show (Jan 2026-11-09: "how much investment is missing, what was built and why"), kept
# per rule group by its construction code <why> (101 food, 102 logistics, 103 business, 105 profiles, 106 improvements,
# 107 towns and buildings) until the next pass: pp_cplan_dran_<why> (the group ran; the hand-on at the pass's end
# reads it), pp_cplan_dhad_ / _dspent_ / _dn_ (the purse it started with, gold it spent, constructions started),
# pp_cplan_dwait_ / _dwn_ (the gold and the number of the constructions it wanted that waited for gold), pp_cplan_dgo_
# / _dml_ (things held back because the market lacks the construction goods / by the market limit), the list
# pp_cplan_log_<why>, the group's situation pp_cplan_ds_<name>, and the last 12 passes
# pp_cplan_hn_<why>_<k> / pp_cplan_hs_<why>_<k> (wanted / spent, k = 1 the last; generated pp_cplan_stats_reset_<why>, at the group's look,
# pp_cplan_history_push). The rules never read any of these numbers: the window only.
# Location, per rule group <why> that built here in the last pass (a location with two construction slots can get
# two constructions in one pass, from two groups or from one: in game 2026-11-10 one line per location named both
# buildings in both groups' lists with the later one's cost and reason): the list pp_cplan_log_types_<why> (its
# buildings here), pp_cplan_log_cost_<why> (the gold it paid here, two constructions added up), pp_cplan_log_val_<why>
# (the reason value + 100: the food store a year from now in months, market access %, population % of capacity,
# payback years) and pp_cplan_log_step_<why> (the food rule's step, a profile's rule; towns and buildings: 1 a
# building, 2 a town or city upgrade, 3 a building's upgrade). A town or city upgrade is no building: that group
# writes the entry itself and sets pp_cplan_log_rank, the window then names the upgrade (type pp_cplan_rank_upgrade);
# pp_cplan_bz_pick / pp_cplan_bz_roi during the business group only.

# ---- Script time (Jan 2026-11-10: "The monthly pass takes 0.4 seconds. That is substantially too long ... it needs to
# be built so that it doesn't use unnecessary script time"; measured 0.32-0.39 s a pass in a 330-location country, 0.20 s
# of it the business pick over every free site against every business type). ----
# The pass still runs every month, but it is cheap: the purses fill (arithmetic), the business group works out the best
# business of a FEW sites (the next ones in a fixed order; the pick stays on the location), and every rule group LOOKS
# (walks what it wants, best first) only in its months ([construction_plan] look_months, pp_cplan_looks_<name>). Between
# its looks a group does one thing only: when it saves for something and its purse can now pay for it, it goes back to
# that one place and runs its rule there again (pp_cplan_group_target), with every guard of a look. What a group
# found at a look (numbers, list, what it saves for) stays for the window until its next look.

# Country scope: the monthly pass.
pp_cplan_run = {
	pp_cplan_pass_begin = yes
	# The rule groups' order turns with the game's month, so every group goes first twice a year (six groups, twelve
	# months). Since the purses the order no longer decides who gets the gold: only who gets a free construction slot
	# of a location first, among the groups that look in the same month. Stateless: the month is the game's. Who may
	# build what in a location does not depend on the order (a profile takes from the groups what it sets,
	# pp_cplan_*_ok).
	if = {
		limit = { OR = { current_month = 1 current_month = 7 } }
		pp_cplan_group_profiles = yes
		pp_cplan_group_food = yes
		pp_cplan_group_logistics = yes
		pp_cplan_group_improve = yes
		pp_cplan_group_business = yes
		pp_cplan_group_country = yes
	}
	else_if = {
		limit = { OR = { current_month = 2 current_month = 8 } }
		pp_cplan_group_food = yes
		pp_cplan_group_logistics = yes
		pp_cplan_group_improve = yes
		pp_cplan_group_business = yes
		pp_cplan_group_country = yes
		pp_cplan_group_profiles = yes
	}
	else_if = {
		limit = { OR = { current_month = 3 current_month = 9 } }
		pp_cplan_group_logistics = yes
		pp_cplan_group_improve = yes
		pp_cplan_group_business = yes
		pp_cplan_group_country = yes
		pp_cplan_group_profiles = yes
		pp_cplan_group_food = yes
	}
	else_if = {
		limit = { OR = { current_month = 4 current_month = 10 } }
		pp_cplan_group_improve = yes
		pp_cplan_group_business = yes
		pp_cplan_group_country = yes
		pp_cplan_group_profiles = yes
		pp_cplan_group_food = yes
		pp_cplan_group_logistics = yes
	}
	else_if = {
		limit = { OR = { current_month = 5 current_month = 11 } }
		pp_cplan_group_business = yes
		pp_cplan_group_country = yes
		pp_cplan_group_profiles = yes
		pp_cplan_group_food = yes
		pp_cplan_group_logistics = yes
		pp_cplan_group_improve = yes
	}
	else = {
		pp_cplan_group_country = yes
		pp_cplan_group_profiles = yes
		pp_cplan_group_food = yes
		pp_cplan_group_logistics = yes
		pp_cplan_group_improve = yes
		pp_cplan_group_business = yes
	}
	# urban rights of the Towns and Buildings group: they cost no gold, so they have no part of it and no turn; they
	# are looked at in their own months
	if = {
		limit = { pp_cplan_looks_rights = yes }
		pp_cplan_country_rights = yes
	}
	pp_cplan_pass_end = yes
	# Never runs: tells the script check that the window's button scopes (set by the GUI with AddScope) exist, so the
	# log has no "used but never set" lines for them.
	if = {
		limit = { always = no }
		save_scope_as = pp_key
		save_scope_as = pp_dir
		save_scope_as = pp_n
		save_scope_as = pp_slot # Location Profiles
		save_scope_as = pp_field # Location Profiles
		save_scope_as = pp_col # Location Profiles
		pp_cplan_declare_flags = yes
		pp_cplan_country_declare = yes # Towns and Buildings
		pp_lprof_declare_flags = yes
		set_variable = { name = pp_cplan_ai_test value = yes } # set only by the console (test runs)
		if = {
			limit = { has_variable = pp_cplan_flag }
			remove_variable = pp_cplan_flag
		}
	}
}

# Country scope: a pass begins: the scopes every rule reads, nobody has looked yet (pp_cplan_pass_reset), and the
# budgets that save (Jan 2026-11-10; until then every pass offered all the gold above the reserve anew, nothing was
# saved, and a group walked past what it could not pay for and built whatever cheaper thing fitted: cheap buildings
# won and expensive ones never came). Every rule group has a purse: the gold in no purse yet is shared by the weights,
# a group that does not count gives its purse back, and the purses shrink alike when they hold more than the gold above
# the reserve (pp_cplan_purses_fill). A construction is paid from the purse of the group that starts it and must fit
# in it (pp_cplan_construct_scoped); the first thing a group wants and cannot pay for is what it saves for, and from
# then on it builds nothing more (pp_cplan_note_wait).
pp_cplan_pass_begin = {
	save_scope_as = pp_cplan_country
	save_scope_as = actor # building conditions read the builder as scope:actor
	clear_variable_list = pp_cplan_log
	set_variable = { name = pp_cplan_started value = 100 }
	set_variable = { name = pp_cplan_spent value = 100 }
	remove_variable = pp_cplan_hit
	remove_variable = pp_cplan_noted
	remove_variable = pp_cplan_wait
	remove_variable = pp_cplan_mlim
	pp_cplan_pass_reset = yes
	# a construction's reason for the window (pp_cplan_construct_now): each rule group sets them before it builds
	save_temporary_scope_value_as = { name = pp_cplan_rv value = 0 }
	save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
	pp_cplan_purses_fill = yes
	# the market limit counts what is under construction afresh only in its months: between them the counts of the
	# last count stand on the markets' centres, raised by what the plan itself starts (constructions take about a
	# year; counting a market means walking its locations)
	if = {
		limit = { pp_cplan_looks_market_count = yes }
		pp_cplan_markets_clear = yes
	}
}

# Country scope: a pass ends: a group that looked in this pass and saves for nothing hands what is left of its purse
# to the groups that do save; the history of the window's charts moves on.
pp_cplan_pass_end = {
	remove_variable = pp_cplan_hit
	remove_variable = pp_cplan_noted
	remove_variable = pp_cplan_wait
	remove_variable = pp_cplan_mlim
	pp_cplan_purses_hand_on = yes
	pp_cplan_history_push = yes
	# test runs: one line per monthly pass (ppc plan-report counts the months by it; debug_log_date writes nothing)
	if = {
		limit = { has_variable = pp_cplan_ai_test }
		debug_log = PP_CPLAN_TLOG_PASS
	}
}

# ---- The rule groups (country scope, inside pp_cplan_run; each with a weight above 0 pays from its purse) ----
# Best pick first (Jan 2026-11-10): at a look a group goes through what it wants in its own order of importance (food:
# the hungriest province first; logistics: the most urgent location; improvements: the fullest; businesses: the soonest
# payback counting the time to save; towns and buildings and the locations: their own order). The first thing it wants
# and cannot pay for from its purse is what it saves for (pp_cplan_note_wait keeps the location, the building type,
# the cost and the reason for the window), and from then on it builds nothing more, even things that would fit: cheap
# things no longer win because they are cheap. At the look it still goes through the rest: what it cannot pay for is
# counted, not built, so the window shows the gold that would have started it all (Jan 2026-11-09: "how much investment
# is needed, correctly calculated from the last iteration"). Things stopped for another reason (cannot be built, no
# workers, the market lacks the construction goods, the market limit) are skipped and are not what it saves for.
# A location with a construction under way (pp_cplan_site_free) cannot start one, so the logistics and improvement
# groups do not look for a building there (it still counts for their situation).
# The sixth group, Towns and Buildings (pp_cplan_group_country, code 107), is construction_plan_country.py's.

# Country scope: a rule group looks (its code $why$): what its last look left for the window goes (generated
# pp_cplan_stats_reset_<why>: its list, numbers, situation), and so does what it saved for: the look finds it again.
# The window keeps that it looked and the purse it started with; pp_cplan_now_<why> tells the pass's end that it looked
# in this pass (the hand-on, the chart).
pp_cplan_group_start = {
	pp_cplan_stats_reset_$why$ = yes
	pp_cplan_save_clear = { why = $why$ }
	set_variable = { name = pp_cplan_dran_$why$ value = yes }
	set_variable = { name = pp_cplan_now_$why$ value = yes }
	set_variable = { name = pp_cplan_dhad_$why$ value = { value = pp_cplan_purse_n_$why$ add = 100 } }
}

# Country scope: the rule group $why$ saves for nothing any more (its look starts, it stopped counting, or its purse
# can pay now and it goes for it). Towns and Buildings' town or city mark (pp_cplan_save_rank_107) goes where that
# group clears (no other group ever sets one).
pp_cplan_save_clear = {
	remove_variable = pp_cplan_save_cost_$why$
	remove_variable = pp_cplan_save_loc_$why$
	remove_variable = pp_cplan_save_type_$why$
	remove_variable = pp_cplan_save_rv_$why$
	remove_variable = pp_cplan_save_rs_$why$
}

# Country scope, in a pass in which the rule group $why$ does not look: when it saves for something and its purse can
# pay for it now, it goes back to that one place and runs its rule there again ($do$, location scope: every guard
# and condition of a look, so a thing that is no longer wanted or possible is simply not built). It lets go of what
# it saved for first: the construction then pays like any level, and if the gold falls short after all it is saved
# for again (pp_cplan_note_wait). Nothing else is walked: this is the whole cost of a group between its looks.
# scope:pp_cplan_btype, scope:pp_cplan_rv / _rs and scope:pp_cplan_trank (1 a town, 2 a city upgrade, else 0) carry
# what was saved for to $do$.
pp_cplan_group_target = {
	if = {
		limit = {
			has_variable = pp_cplan_save_cost_$why$
			has_variable = pp_cplan_save_loc_$why$
			pp_cplan_purse_n_$why$ >= pp_cplan_save_cost_n_$why$
		}
		var:pp_cplan_save_loc_$why$ = { save_scope_as = pp_cplan_target }
		if = {
			limit = { has_variable = pp_cplan_save_type_$why$ }
			var:pp_cplan_save_type_$why$ = { save_scope_as = pp_cplan_btype }
		}
		if = {
			limit = { has_variable = pp_cplan_save_rv_$why$ }
			save_temporary_scope_value_as = { name = pp_cplan_rv value = var:pp_cplan_save_rv_$why$ }
		}
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
		if = {
			limit = { has_variable = pp_cplan_save_rs_$why$ }
			save_temporary_scope_value_as = { name = pp_cplan_rs value = var:pp_cplan_save_rs_$why$ }
		}
		save_temporary_scope_value_as = { name = pp_cplan_trank value = pp_cplan_save_rank_n_$why$ }
		pp_cplan_save_clear = { why = $why$ }
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
		scope:pp_cplan_target = {
			if = {
				limit = { owner ?= scope:pp_cplan_country }
				$do$ = yes
			}
		}
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
	}
}

# The player's "Locations" group (pp_location_profiles.txt): the location profiles, whose rules have priority in their
# locations (the global groups still build there what a profile does not set, pp_cplan_*_ok), and the Location Plan's
# marks ("Also build here"), which add to them and switch nothing off.
pp_cplan_group_profiles = {
	pp_lprof_run = yes
}

# Food: looks in its months, else only goes for what it saves for.
pp_cplan_group_food = {
	if = {
		limit = { pp_cplan_food_w > 0 }
		if = {
			limit = { pp_cplan_looks_food = yes }
			pp_cplan_look_food = yes
		}
		else = {
			pp_cplan_group_target = { why = 101 do = pp_cplan_food_target }
		}
	}
}

# Country scope: the food group's look: per province (pp_cplan_food_province), the hungriest first: the store a year
# from now in a normal year, lowest first. That store is worked out ONCE a province (it walks the province's locations
# several times) and kept on the province for the order and the rule (pp_cplan_fy, + 1000; the rule removes it). A
# province without a food store has no step to run.
pp_cplan_look_food = {
	pp_cplan_group_start = { why = 101 }
	every_province = {
		limit = { has_variable = pp_stored_food_months }
		set_variable = { name = pp_cplan_fy value = { value = pp_cplan_food_in_a_year add = 1000 } }
	}
	ordered_province = {
		limit = { has_variable = pp_cplan_fy }
		order_by = pp_cplan_food_order
		max = 100000
		check_range_bounds = no
		pp_cplan_food_province = yes
	}
}

# Location scope (where the food group saved for something): the food rule of its province again.
pp_cplan_food_target = {
	province ?= { pp_cplan_food_province = yes }
}

# Country scope: the logistics group's look, per location: where market access without event modifiers is below the
# line, the most urgent first. The cheap checks come first in the limit (whose location, the profile's switches),
# then the access.
pp_cplan_look_logistics = {
	pp_cplan_group_start = { why = 102 }
	ordered_owned_location = {
		limit = {
			pp_cplan_logistics_ok = yes
			pp_cplan_logistics_wanted = yes
		}
		order_by = pp_logistics_urgency_weight
		max = 200
		check_range_bounds = no
		pp_cplan_logistics_here = yes
		# the window: the lowest of the locations below the line (scope:pp_cplan_rv: the access here, % + 100)
		scope:pp_cplan_country = {
			change_variable = { name = pp_cplan_ds_logistics_below add = 1 }
			if = {
				limit = { var:pp_cplan_ds_logistics_lowest > scope:pp_cplan_rv }
				set_variable = { name = pp_cplan_ds_logistics_lowest value = scope:pp_cplan_rv }
			}
		}
	}
}

# Location scope (below the line): the logistics building this location can have, where a construction can start.
pp_cplan_logistics_here = {
	# the window: market access without event effects, in % (+ 100)
	save_temporary_scope_value_as = { name = pp_cplan_rv value = { value = pp_cplan_access_normal multiply = 100 add = 100 } }
	save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
	scope:pp_cplan_country = { remove_variable = pp_cplan_noted }
	if = {
		limit = { pp_cplan_site_free = yes }
		pp_cplan_try_logistics_here = yes
	}
}

# Location scope (where the logistics group saved for something): its rule here again, if it still holds.
pp_cplan_logistics_target = {

		limit = {
			pp_cplan_logistics_ok = yes
			pp_cplan_logistics_wanted = yes
		}
		pp_cplan_logistics_here = yes
	}
}

# Country scope: the improvement group's look (Jan 2026-11-08): where population over capacity reaches the player's
# line, the improvement that adds the most capacity per gold; the fullest locations first.
pp_cplan_look_improve = {
	pp_cplan_group_start = { why = 106 }
	ordered_owned_location = {
		limit = {
			pp_cplan_improve_ok = yes
			location_population_percentage >= scope:pp_cplan_country.pp_cplan_improve_line
		}
		order_by = pp_cplan_fill_here
		max = 200
		check_range_bounds = no
		pp_cplan_improve_here = yes
		# the window: the fullest location over the line (scope:pp_cplan_rv: population in % of capacity, + 100)
		scope:pp_cplan_country = {
			change_variable = { name = pp_cplan_ds_improve_over add = 1 }
			if = {
				limit = { var:pp_cplan_ds_improve_fullest < scope:pp_cplan_rv }
				set_variable = { name = pp_cplan_ds_improve_fullest value = scope:pp_cplan_rv }
			}
		}
	}
}

# Location scope (over the line): the improvement that adds the most capacity per gold here, where a construction can
# start.
pp_cplan_improve_here = {
	# the window: population in % of capacity (+ 100)
	save_temporary_scope_value_as = { name = pp_cplan_rv value = { value = location_population_percentage multiply = 100 add = 100 } }
	save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
	scope:pp_cplan_country = { remove_variable = pp_cplan_noted }
	if = {
		limit = { pp_cplan_site_free = yes }
		pp_cplan_try_improve_here = yes
	}
}

# Location scope (where the improvement group saved for something): its rule here again, if it still holds.
pp_cplan_improve_target = {
	if = {
		limit = {
			pp_cplan_improve_ok = yes
			location_population_percentage >= scope:pp_cplan_country.pp_cplan_improve_line
		}
		pp_cplan_improve_here = yes
	}
}

# Businesses (Jan 2026-11-09): every building that makes goods, wherever a level pays back within the player's line.
# Script time (2026-11-10): scoring every free site against every business type was two thirds of the pass (0.20 s for
# 330 sites x 224 types), and the market limit lets only a level or so of a good start in a market at a time, so
# nearly all of it was thrown away. Now:
#  1. every pass (pp_cplan_business_refresh) the best business of a FEW sites is worked out, the next ones in a fixed
#     order (pp_cplan_bz_window: [construction_plan] business_sites, or as many as it takes to see every location
#     within business_cycle_months), and kept on the location (pp_cplan_bz_pick, _roi, _cost: the generated
#     pp_cplan_business_pick, unchanged: within the line, the workers, the market limit, the construction goods);
#  2. at a look (pp_cplan_look_business: every month while the group does not save, else in its look months) the
#     stored picks are ranked by payback INCLUDING the time to save (pp_cplan_bz_order: payback years + the gold the
#     purse lacks for it / the gold the group receives a year), and the best few (pp_cplan_bz_tries) are built: each
#     site works its pick out afresh first (pp_cplan_business_here), so nothing is built on a stale estimate; the
#     first that does not fit in the purse is what the group saves for;
#  3. while it saves and its purse cannot pay yet, it only keeps refreshing; once the purse can pay it goes for that
#     site (pp_cplan_group_target).
# The cost of a pass no longer grows with locations x business types: only the refresh scores sites, a fixed few.
pp_cplan_group_business = {
	if = {
		limit = { pp_cplan_business_w > 0 }
		pp_cplan_business_refresh = yes
		if = {
			limit = {
				OR = {
					NOT = { pp_cplan_saving = { why = 103 } }
					pp_cplan_looks_business = yes
				}
			}
			pp_cplan_look_business = yes
		}
		else = {
			pp_cplan_group_target = { why = 103 do = pp_cplan_business_here }
		}
	}
}

# Country scope, every pass: the business picks of the next few sites. Every owned location has a number in the
# order the plan first saw it (pp_cplan_seq, counted on the country as pp_cplan_seq_n, both + 100); the pass takes the
# numbers after the country's place in that order (pp_cplan_cursor) up to pp_cplan_bz_window more, then moves the
# place on, back to the start after the last number. So every location's turn comes round, each exactly once a cycle.
# The pass finds its few without a walk over the country: a location is put on the list of its block of the order
# when it gets its number (pp_cplan_bzb_<n>, generated pp_cplan_business_block), and the pass reads only the lists of
# the blocks its numbers fall in (generated pp_cplan_business_walk). In game 2026-11-10 the walk over every owned
# location with its two comparisons was 11 of the refresh's 21 ms a pass in a country of 424 locations. New
# locations get their numbers in the months of the country's can-build check (pp_cplan_bz_<type>), and in the first
# pass.
pp_cplan_business_refresh = {
	if = {
		limit = {
			OR = {
				NOT = { has_variable = pp_cplan_bz_known }
				pp_cplan_looks_business_types = yes
			}
		}
		pp_cplan_business_types_clear = yes
		pp_cplan_business_types = yes
		set_variable = { name = pp_cplan_bz_known value = yes }
		# the order starts afresh where the blocks' lists are not kept yet (the first pass; a game from before them)
		if = {
			limit = { NOT = { has_variable = pp_cplan_bzb_kept } }
			set_variable = { name = pp_cplan_bzb_kept value = yes }
			set_variable = { name = pp_cplan_seq_n value = 100 }
			set_variable = { name = pp_cplan_cursor value = 100 }
			every_owned_location = {
				limit = { has_variable = pp_cplan_seq }
				remove_variable = pp_cplan_seq
			}
		}
		# locations without a number (all of them at first, later the new ones): the next number and its block's list
		every_owned_location = {
			limit = { NOT = { has_variable = pp_cplan_seq } }
			scope:pp_cplan_country = { change_variable = { name = pp_cplan_seq_n add = 1 } }
			set_variable = { name = pp_cplan_seq value = scope:pp_cplan_country.var:pp_cplan_seq_n }
			pp_cplan_business_block = yes
		}
	}
	if = {
		limit = { NOT = { has_variable = pp_cplan_seq_n } }
		set_variable = { name = pp_cplan_seq_n value = 100 }
	}
	if = {
		limit = { NOT = { has_variable = pp_cplan_cursor } }
		set_variable = { name = pp_cplan_cursor value = 100 }
	}
	save_temporary_scope_value_as = { name = pp_cplan_from value = var:pp_cplan_cursor }
	save_temporary_scope_value_as = { name = pp_cplan_to value = { value = var:pp_cplan_cursor add = pp_cplan_bz_window } }
	pp_cplan_business_walk = yes
	set_variable = { name = pp_cplan_cursor value = scope:pp_cplan_to }
	if = {
		limit = { var:pp_cplan_cursor >= var:pp_cplan_seq_n }
		set_variable = { name = pp_cplan_cursor value = 100 }
	}
}

# Location scope, from pp_cplan_business_walk: it is this location's turn. A site that cannot take a business now
# (a construction under way, a profile that keeps them out, no market) keeps the pick it had: the look works it out
# afresh before it builds.
pp_cplan_business_turn_here = {
	if = {
		limit = { pp_cplan_business_site = yes }
		pp_cplan_business_pick = yes
	}
}

# Country scope: the business group's look: the stored picks, the soonest payback counting the time to save first;
# the best few are tried. Not while it has neither gold saved nor gold coming in: nothing could be built or sensibly
# saved for, and the window says that it did not look (pp_cplan_ds_business_skipped).
pp_cplan_look_business = {
	pp_cplan_group_start = { why = 103 }
	if = {
		limit = {
			OR = {
				pp_cplan_purse_n_103 > 0.01
				pp_cplan_in_n_103 > 0.01
			}
		}
		# the window: the sites with a stored pick and the quickest payback among them (no site is scored here)
		every_owned_location = {
			limit = { has_variable = pp_cplan_bz_pick }
			save_temporary_scope_value_as = { name = pp_cplan_rv value = { value = pp_cplan_bz_years add = 100 } }
			scope:pp_cplan_country = {
				change_variable = { name = pp_cplan_ds_business_sites add = 1 }
				if = {
					limit = { var:pp_cplan_ds_business_best > scope:pp_cplan_rv }
					set_variable = { name = pp_cplan_ds_business_best value = scope:pp_cplan_rv }
				}
			}
		}
		ordered_owned_location = {
			limit = {
				has_variable = pp_cplan_bz_pick
				pp_cplan_site_free = yes
			}
			order_by = pp_cplan_bz_order
			max = pp_cplan_bz_tries
			check_range_bounds = no
			pp_cplan_business_here = yes
		}
	}
	else = {
		set_variable = { name = pp_cplan_ds_business_skipped value = 101 }
	}
}

# Location scope (a site with a stored pick, or where the group saved for a business): while the group does not save,
# the site works its best business out afresh (every guard: pp_cplan_business_site, pp_cplan_business_pick) and one
# level of it is built through the plan's construct path; a pick that was built or is gone leaves the location. Once
# the group saves, the remaining picks of the look are only counted as waiting for gold, at their stored cost.
pp_cplan_business_here = {
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_noted
		remove_variable = pp_cplan_hit
	}
	if = {
		limit = { pp_cplan_saving = { why = 103 } }
		if = {
			limit = { has_variable = pp_cplan_bz_cost }
			save_temporary_scope_value_as = { name = pp_cplan_wc value = var:pp_cplan_bz_cost }
			scope:pp_cplan_country = {
				change_variable = { name = pp_cplan_dwait_103 add = scope:pp_cplan_wc }
				change_variable = { name = pp_cplan_dwn_103 add = 1 }
			}
		}
	}
	else_if = {
		limit = { pp_cplan_business_site = yes }
		pp_cplan_business_pick = yes
		if = {
			limit = { has_variable = pp_cplan_bz_pick }
			# the window: the pick's payback in years (+ 100)
			save_temporary_scope_value_as = { name = pp_cplan_rv value = { value = pp_cplan_bz_years add = 100 } }
			save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
			var:pp_cplan_bz_pick = { save_scope_as = pp_cplan_btype }
			pp_cplan_construct_scoped = { why = 103 }
			if = {
				limit = { scope:pp_cplan_country = { has_variable = pp_cplan_hit } }
				remove_variable = pp_cplan_bz_pick
				remove_variable = pp_cplan_bz_roi
				remove_variable = pp_cplan_bz_cost
			}
		}
	}
	scope:pp_cplan_country = { remove_variable = pp_cplan_hit }
}

# Province scope: the food rule, one construction a month, the first of these that builds (baseline rules, Jan
# 2026-11-08). Every check reads the game as it stands; nothing is kept from pass to pass. The hunger checks read the
# store a year from now in a normal year (pp_cplan_food_in_a_year: this year's harvest and spoilage taken out).
#   1. famine (below the famine line): a Tavern in the province capital, where its market holds victuals;
#   2. hungry (below pp_cplan_hungry_months): a staple food maker (crop farm, orchard, fishery, herd, forest village),
#      the line that pays back fastest, in the province location where it pays back fastest;
#   3. a Granary while the store holds less than the line's months, is nearly full and a normal month adds food
#      (before the kitchen: food a kitchen adds to a full, capped store only spoils; AI test run 2026-11-09: with the
#      kitchen first, the Cookshops took the capital year after year, one construction at a time, and 15 years built
#      no Granary in the 22-33 provinces where one was due);
#   4. a kitchen whenever the Cookshop budget allows (its successor first);
#   5. hungry and nothing above built: a Tavern, where its market holds victuals (provinces that cannot farm);
#   6. a Grange where the store holds 24 months and a normal month adds the line's share on top;
#   7. a Victualling Yard: the next level while it pays back within the line, a first one where victuals cost at least
#      their default price.
# Profile locations whose profile switched the food rule off are left out; a profile with a staple food rule keeps the
# farm step out, one with a victuals rule the Grange and Yard steps. While a farm or Tavern of the province has a level
# under construction, the hunger steps 2 and 5 wait (the store only moves once it stands).
# The provinces come hungriest first (pp_cplan_group_food). The first step the group's purse cannot pay for is what
# the food group saves for; from then on no province builds, but every province is still gone through: the first step
# that waits for gold is counted for the
# window (pp_cplan_note_wait, once a province: the rule's one construction a month), and the province's situation
# (famine, hungry, a Granary or a Grange due) too. The store a year from now is read once (scope:pp_cplan_fy, the
# hunger and famine triggers read it), the Granary and Grange checks once (scope:pp_cplan_gd / _rd, 1 = due).
pp_cplan_food_province = {
	save_scope_as = pp_cplan_province
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
	}
	if = {
		limit = { has_variable = pp_stored_food_months }
		# the store a year from now: the look worked it out once for the order and left it here (pp_cplan_fy, + 1000);
		# a single province outside a look (what the group saved for) works it out now
		if = {
			limit = { has_variable = pp_cplan_fy }
			save_temporary_scope_value_as = { name = pp_cplan_fy value = { value = var:pp_cplan_fy subtract = 1000 } }
		}
		else = {
			save_temporary_scope_value_as = { name = pp_cplan_fy value = pp_cplan_food_in_a_year }
		}
		save_temporary_scope_value_as = { name = pp_cplan_rv value = { value = scope:pp_cplan_fy add = 100 } }
		save_temporary_scope_value_as = { name = pp_cplan_gd value = 0 }
		save_temporary_scope_value_as = { name = pp_cplan_rd value = 0 }
		if = {
			limit = { pp_cplan_granary_due = yes }
			save_temporary_scope_value_as = { name = pp_cplan_gd value = 1 }
		}
		if = {
			limit = { pp_cplan_grange_due = yes }
			save_temporary_scope_value_as = { name = pp_cplan_rd value = 1 }
		}
		# the window: the province's situation (counted at a look only)
		scope:pp_cplan_country = {
			if = {
				limit = { has_variable = pp_cplan_now_101 }
				change_variable = { name = pp_cplan_ds_food_provinces add = 1 }
			}
			if = {
				limit = { has_variable = pp_cplan_now_101 scope:pp_cplan_fy < pp_cplan_famine_months }
				change_variable = { name = pp_cplan_ds_food_famine add = 1 }
			}
			else_if = {
				limit = { has_variable = pp_cplan_now_101 scope:pp_cplan_fy < pp_cplan_hungry_months }
				change_variable = { name = pp_cplan_ds_food_hungry add = 1 }
			}
			if = {
				limit = { has_variable = pp_cplan_now_101 scope:pp_cplan_gd > 0.5 }
				change_variable = { name = pp_cplan_ds_food_granary add = 1 }
			}
			if = {
				limit = { has_variable = pp_cplan_now_101 scope:pp_cplan_rd > 0.5 }
				change_variable = { name = pp_cplan_ds_food_grange add = 1 }
			}
		}
		# 1. famine: a Tavern
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 1 }
		if = {
			limit = { pp_cplan_famine = yes }
			province_capital ?= {
				if = {
					limit = {
						pp_cplan_food_ok = yes
						pp_cplan_victuals_here = yes
					}
					pp_cplan_try_tavern_here = yes
				}
			}
		}
		# 2. hungry: a farm
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 2 }
		if = {
			limit = {
				pp_cplan_may_try = yes
				pp_cplan_hungry = yes
				NOT = { any_location_in_province = { pp_cplan_food_queued = yes } }
			}
			ordered_location_in_province = {
				# only sites that can start a construction: a busy one among the best sites took a try and built
				# nothing, and the province then went on to a Tavern although it can farm. The best line's return is
				# worked out once a location, for the order (it asks every farm line's can-build check): a site without
				# a line that pays ends up last and its try builds nothing (pp_cplan_try_farm_here)
				limit = {
					pp_cplan_farm_ok = yes
					pp_cplan_site_free = yes
				}
				order_by = pp_cplan_farm_best_roi
				max = pp_cplan_farm_sites
				check_range_bounds = no
				if = {
					limit = { pp_cplan_may_try = yes }
					pp_cplan_try_farm_here = yes
				}
			}
		}
		# 3. a Granary, while it is due (before the kitchen: a full, capped store spoils what a kitchen adds)
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 3 }
		if = {
			limit = {
				pp_cplan_may_try = yes
				scope:pp_cplan_gd > 0.5
			}
			province_capital ?= {
				if = {
					limit = { pp_cplan_food_ok = yes }
					pp_cplan_try_granary_here = yes
				}
			}
		}
		# 4. a kitchen, whenever it can be built
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 4 }
		if = {
			limit = { pp_cplan_may_try = yes }
			province_capital ?= {
				if = {
					limit = { pp_cplan_food_ok = yes }
					pp_cplan_try_kitchen_here = yes
				}
			}
		}
		# 5. hungry and nothing else possible: a Tavern
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 5 }
		if = {
			limit = {
				pp_cplan_may_try = yes
				pp_cplan_hungry = yes
				NOT = { any_location_in_province = { pp_cplan_food_queued = yes } }
			}
			province_capital ?= {
				if = {
					limit = {
						pp_cplan_food_ok = yes
						pp_cplan_victuals_here = yes
					}
					pp_cplan_try_tavern_here = yes
				}
			}
		}
		# 6. a Grange
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 6 }
		if = {
			limit = {
				pp_cplan_may_try = yes
				scope:pp_cplan_rd > 0.5
			}
			province_capital ?= {
				if = {
					limit = { pp_cplan_victuals_ok = yes }
					pp_cplan_try_grange_here = yes
				}
			}
		}
		# 7. a Victualling Yard
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 7 }
		if = {
			limit = { pp_cplan_may_try = yes }
			every_location_in_province = {
				limit = {
					pp_cplan_victuals_ok = yes
					OR = {
						pp_victualling_yard_site = yes
						is_market_center = yes
					}
				}
				if = {
					limit = { pp_cplan_may_try = yes }
					pp_cplan_try_yard_here = yes
				}
			}
		}
	}
	remove_variable = pp_cplan_fy
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
	}
}

# Location scope: start one level of $type$ here and record it ($why$: 101 food, 102 logistics, 103 business, 105 a
# location profile, 106 improvements, 107 towns and buildings).
pp_cplan_construct = {
	building_type:$type$ = { save_scope_as = pp_cplan_btype }
	pp_cplan_construct_scoped = { why = $why$ }
}

# Location scope: the same for the building type scope:pp_cplan_btype. Only where a construction can start
# (pp_cplan_site_free: nothing is under construction here, whoever started it). Never a
# level for a building that is closed: whoever closed it (the player or the game's Close and Open Buildings
# automation) found it does not pay, and the plan does not argue (Jan 2026-11-09: the plan and the game's automation
# must not undo each other).
# The market limit (Jan 2026-11-10, against 500 horse farms after one good month): for the rule groups it holds for
# (pp_cplan_limits_market_<why>: Businesses, profile rules and marks) a level of a business type starts only while its
# market has room for the good (pp_cplan_market_do: scope:pp_cplan_mok); a level stopped by it is counted apart
# (pp_cplan_note_market) and is not waiting for gold. This is the ONE construct path, so the limit holds for
# everything those groups build.
# The gold: the level's cost (the engine's formula) must fit in the purse of the rule group $why$ and in the gold
# above the reserve (pp_cplan_affordable), and the group must not be saving yet (pp_cplan_saving): the first thing it
# cannot pay for is what it saves for, and it builds nothing more in the pass. A level the rule wants that it does
# not start for either reason is counted for the window (pp_cplan_note_wait).
pp_cplan_construct_scoped = {
	if = {
		limit = {
			pp_cplan_site_free = yes
			pp_cplan_bt_queued < 0.5
			NOT = {
				any_buildings_in_location = {
					building_type = scope:pp_cplan_btype
					building_level > 0
					is_opened = no
				}
			}
		}
		save_temporary_scope_value_as = { name = pp_cplan_mok value = 1 }
		if = {
			limit = { pp_cplan_limits_market_$why$ = yes }
			pp_cplan_market_do = { do = gate }
		}
		if = {
			limit = { scope:pp_cplan_mok < 0.5 }
			pp_cplan_note_market = { why = $why$ }
		}
		else = {
			pp_cplan_btype_data = yes
			if = {
				limit = {
					NOT = { pp_cplan_saving = { why = $why$ } }
					pp_cplan_affordable = { why = $why$ }
				}
				pp_cplan_construct_now = { why = $why$ }
			}
			else = {
				pp_cplan_note_wait = { why = $why$ }
			}
		}
	}
}

# Location scope, after pp_cplan_btype_data: the level of scope:pp_cplan_btype the rule group $why$ wants here waits for
# gold. The window counts it and its cost, once per decision (pp_cplan_noted: a province of the food rule, a location of
# the profiles, one location of the other groups); pp_cplan_wait tells a location profile's rule why it did not build.
# The first such level of the pass is what the group saves for from now on (the location, the building type, the
# cost; pp_cplan_save_cost_<why> set = the group saves and builds nothing more in this pass).
pp_cplan_note_wait = {
	save_temporary_scope_value_as = { name = pp_cplan_wc value = pp_cplan_est_cost }
	save_temporary_scope_as = pp_cplan_wsite
	scope:pp_cplan_country = {
		set_variable = { name = pp_cplan_wait value = yes }
		if = {
			limit = { NOT = { has_variable = pp_cplan_noted } }
			set_variable = { name = pp_cplan_noted value = yes }
			change_variable = { name = pp_cplan_dwait_$why$ add = scope:pp_cplan_wc }
			change_variable = { name = pp_cplan_dwn_$why$ add = 1 }
		}
		if = {
			limit = { NOT = { has_variable = pp_cplan_save_cost_$why$ } }
			set_variable = { name = pp_cplan_save_cost_$why$ value = { value = scope:pp_cplan_wc add = 100 } }
			set_variable = { name = pp_cplan_save_loc_$why$ value = scope:pp_cplan_wsite }
			set_variable = { name = pp_cplan_save_type_$why$ value = scope:pp_cplan_btype }
			set_variable = { name = pp_cplan_save_rv_$why$ value = scope:pp_cplan_rv }
			set_variable = { name = pp_cplan_save_rs_$why$ value = scope:pp_cplan_rs }
		}
	}
}

# Location scope: the level of scope:pp_cplan_btype the rule group $why$ wants here was stopped by the market limit:
# the window counts it apart (not waiting for gold), pp_cplan_mlim tells a location profile's rule or mark why.
pp_cplan_note_market = {
	scope:pp_cplan_country = {
		set_variable = { name = pp_cplan_mlim value = yes }
		change_variable = { name = pp_cplan_dml_$why$ add = 1 }
	}
}

# Any scope: the rule group $why$ wanted something the market lacks the construction goods for: the window counts
# it (in game 2026-11-10 such things were invisible: a Library needs books, a town glass, the pane said "wanted 0").
pp_cplan_note_goods = {
	scope:pp_cplan_country = {
		change_variable = { name = pp_cplan_dgo_$why$ add = 1 }
	}
}

# Location scope: the output of the good $g$ under construction in this location's market is counted for the pass
# (once a market and good: every level under construction there of the buildings whose main good it is, whoever
# started them) and kept on the market's centre location (market.location) as pp_cplan_uc_$g$ (+ 100); the country's
# list pp_cplan_markets keeps those centres, for the clearing at the pass's end. Not on the market itself: a market
# scope holds no variables (in game 2026-11-10: "This scope doesn't support variables. Scope: Market Burgos Market",
# about 2,000 error lines a pass, and the limit never held: 39 Stud Farms started in the Burgos market in one pass
# where the market asks for 10.8 horses a month).
# One walk counts every good of the market (in game 2026-11-10, third round: a walk per market and good, over every
# building of every location with a construction, was 7 ms each and 4 to 27 ms in most months): the market's
# locations with a construction, their buildings under construction, and for each of those the generated dispatch
# adds its levels x its recipe's output to its main good's count (pp_cplan_market_count_building). The centre's
# pp_cplan_uc_counted says the market is counted; a good without a count then has nothing under construction.
pp_cplan_market_load = {
	if = {
		limit = { market.location ?= { NOR = { has_variable = pp_cplan_uc_counted has_variable = pp_cplan_uc_$g$ } } }
		market.location ?= {
			set_variable = { name = pp_cplan_uc_counted value = yes }
			save_temporary_scope_as = pp_cplan_this_market
			scope:pp_cplan_country = {
				if = {
					limit = { NOT = { is_target_in_variable_list = { name = pp_cplan_markets target = scope:pp_cplan_this_market } } }
					add_to_variable_list = { name = pp_cplan_markets target = scope:pp_cplan_this_market }
				}
			}
		}
		market ?= {
			every_location_in_market = {
				every_buildings_in_location = {
					limit = { building_levels_under_construction > 0 }
					save_temporary_scope_value_as = { name = pp_cplan_uc_levels value = building_levels_under_construction }
					pp_cplan_market_count_building = yes
				}
			}
		}
	}
}

# A market's centre location, from pp_cplan_market_count_building: scope:pp_cplan_uc_levels levels under construction
# of a building that makes $out$ of the good $g$ a level.
pp_cplan_market_count_add = {
	if = {
		limit = { has_variable = pp_cplan_uc_$g$ }
		change_variable = { name = pp_cplan_uc_$g$ add = { value = scope:pp_cplan_uc_levels multiply = $out$ } }
	}
	else = {
		set_variable = { name = pp_cplan_uc_$g$ value = { value = scope:pp_cplan_uc_levels multiply = $out$ add = 100 } }
	}
}

# Location scope (pp_cplan_market_do = { do = gate }): scope:pp_cplan_mok = 0 where the market has no room for one more
# level's output $out$ of the good $g$.
pp_cplan_market_gate_good = {
	pp_cplan_market_load = { g = $g$ }
	if = {
		limit = { NOT = { pp_cplan_market_room = { g = $g$ out = $out$ } } }
		save_temporary_scope_value_as = { name = pp_cplan_mok value = 0 }
	}
}

# Location scope (pp_cplan_market_do = { do = add }): the plan started a level here that makes $out$ of the good $g$:
# where the pass has counted the market's constructions of it, the count rises (a market not counted yet reads the
# new construction from the game when it is).
pp_cplan_market_add_good = {
	market.location ?= {
		if = {
			limit = { has_variable = pp_cplan_uc_$g$ }
			change_variable = { name = pp_cplan_uc_$g$ add = $out$ }
		}
		# the market is counted and had nothing of the good under construction: this level is its first
		else_if = {
			limit = { has_variable = pp_cplan_uc_counted }
			set_variable = { name = pp_cplan_uc_$g$ value = { value = $out$ add = 100 } }
		}
	}
}

# Country scope: the market limit's counts of the pass are gone.
pp_cplan_markets_clear = {
	every_in_list = {
		variable = pp_cplan_markets
		pp_cplan_market_clear = yes
	}
	clear_variable_list = pp_cplan_markets
}

# Location scope, in pp_cplan_business_pick: the candidate scope:pp_cplan_btype (its return scope:pp_cplan_r is the
# best so far here) becomes the site's pick when the market holds its construction goods ($demand$) and has room for
# one more level's output $out$ of its good $g$ (the market limit); else the site keeps looking and notes why
# (scope:pp_cplan_bz_go / _ml, counted once a site by the pick).
pp_cplan_business_take = {
	if = {
		limit = { NOT = { pp_cplan_goods_here_$demand$ = yes } }
		save_temporary_scope_value_as = { name = pp_cplan_bz_go value = 1 }
	}
	else = {
		pp_cplan_market_load = { g = $g$ }
		if = {
			limit = { pp_cplan_market_room = { g = $g$ out = $out$ } }
			set_variable = { name = pp_cplan_bz_roi value = scope:pp_cplan_r }
			set_variable = { name = pp_cplan_bz_pick value = scope:pp_cplan_btype }
			set_variable = { name = pp_cplan_bz_cost value = pp_cplan_est_cost }
		}
		else = {
			save_temporary_scope_value_as = { name = pp_cplan_bz_ml value = 1 }
		}
	}
}

pp_cplan_construct_now = {
	save_scope_as = pp_cplan_site
	scope:pp_cplan_country = {
		set_variable = { name = pp_cplan_gold_before value = { value = gold add = 1000000 } }
	}
	construct_building = { building_type = scope:pp_cplan_btype }
	scope:pp_cplan_country = {
		save_temporary_scope_value_as = { name = pp_cplan_paid value = { value = var:pp_cplan_gold_before subtract = 1000000 subtract = gold } }
		change_variable = { name = pp_cplan_spent add = scope:pp_cplan_paid }
		change_variable = { name = pp_cplan_started add = 1 }
		change_variable = { name = pp_cplan_dspent_$why$ add = scope:pp_cplan_paid }
		change_variable = { name = pp_cplan_dn_$why$ add = 1 }
		set_variable = { name = pp_cplan_hit value = yes }
		remove_variable = pp_cplan_gold_before
		# the group's purse pays what was really paid (never below nothing: the estimate is within 1 % of the price)
		pp_cplan_purse_pay = { why = $why$ }
		if = {
			limit = { NOT = { is_target_in_variable_list = { name = pp_cplan_log target = scope:pp_cplan_site } } }
			add_to_variable_list = { name = pp_cplan_log target = scope:pp_cplan_site }
		}
		add_to_variable_list = { name = pp_cplan_log_$why$ target = scope:pp_cplan_site }
	}
	# the market limit: one more level of the type's good is under construction in this market now
	pp_cplan_market_do = { do = add }
	# the window, per rule group: what it built here, what that cost (a second construction of the group here in
	# this pass adds up) and why (the group's reason value and step, scope:pp_cplan_rv / _rs)
	add_to_variable_list = { name = pp_cplan_log_types_$why$ target = scope:pp_cplan_btype }
	if = {
		limit = { has_variable = pp_cplan_log_cost_$why$ }
		change_variable = { name = pp_cplan_log_cost_$why$ add = scope:pp_cplan_paid }
	}
	else = {
		set_variable = { name = pp_cplan_log_cost_$why$ value = scope:pp_cplan_paid }
	}
	set_variable = { name = pp_cplan_log_val_$why$ value = scope:pp_cplan_rv }
	set_variable = { name = pp_cplan_log_step_$why$ value = scope:pp_cplan_rs }
	# test runs (pp_cplan_ai_test, set by the console): three lines per construction in debug.log, read by ppc
	# plan-report: the rule group, the building type ("Building Type 'Granary' (350)") and the location ("Location
	# 'Valladolid' (2584)", its id). debug_log gets no data context (in game 2026-11-09: ROOT and saved scopes are null
	# in its text), debug_log_scopes writes the current scope.
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_ai_test } }
		debug_log = PP_CPLAN_TLOG_$why$
		scope:pp_cplan_btype = { debug_log_scopes = no }
		debug_log_scopes = no
	}
}

# Country scope, scope:pp_cplan_paid saved (the gold a construction of the rule group $why$ really took): its purse
# falls by it, never below nothing. The Towns and Buildings group's town and city upgrades pay the same way.
pp_cplan_purse_pay = {
	change_variable = { name = pp_cplan_purse_$why$ subtract = scope:pp_cplan_paid }
	if = {
		limit = { var:pp_cplan_purse_$why$ < 100 }
		set_variable = { name = pp_cplan_purse_$why$ value = 100 }
	}
}

# Location scope: forget what the rule group $why$ built here in the last pass (the window's lists).
pp_cplan_log_clear = {
	clear_variable_list = pp_cplan_log_types_$why$
	remove_variable = pp_cplan_log_cost_$why$
	remove_variable = pp_cplan_log_val_$why$
	remove_variable = pp_cplan_log_step_$why$
}

pp_cplan_construct_food = {

}

# Any scope: variable $from$ -> $to$ on the same scope (a number, or present / absent with _flag).
pp_cplan_copy_num = {
	if = {
		limit = { has_variable = $from$ }
		set_variable = { name = $to$ value = var:$from$ }
	}
	else = {
		remove_variable = $to$
	}
}
pp_cplan_copy_flag = {
	if = {
		limit = { has_variable = $from$ }
		set_variable = { name = $to$ value = yes }
	}
	else = {
		remove_variable = $to$
	}
}

# ---- Settings (scripted GUIs in scripted_guis/pp_construction_plan.txt) ----

# Any scope: flips the presence of the variable $var$.
pp_cplan_flip = {
	if = {
		limit = { has_variable = $var$ }
		remove_variable = $var$
	}
	else = {
		set_variable = { name = $var$ value = yes }
	}
}

# Country scope: the weight $var$ (+ 100) of a rule group: the step scope:pp_n (flag w1..w10, a step of its bar clicked)
# or one step in the direction scope:pp_dir (- / +); 0 = the group is off. $current$ is the weight with its default.
pp_cplan_set_weight = {
	if = {
		limit = { exists = scope:pp_n }
		switch = {
			trigger = scope:pp_n
			flag:w1 = { set_variable = { name = $var$ value = 101 } }
			flag:w2 = { set_variable = { name = $var$ value = 102 } }
			flag:w3 = { set_variable = { name = $var$ value = 103 } }
			flag:w4 = { set_variable = { name = $var$ value = 104 } }
			flag:w5 = { set_variable = { name = $var$ value = 105 } }
			flag:w6 = { set_variable = { name = $var$ value = 106 } }
			flag:w7 = { set_variable = { name = $var$ value = 107 } }
			flag:w8 = { set_variable = { name = $var$ value = 108 } }
			flag:w9 = { set_variable = { name = $var$ value = 109 } }
			flag:w10 = { set_variable = { name = $var$ value = 110 } }
		}
	}
	else = {
		pp_cplan_step_var = { var = $var$ current = $current$ step = 1 min = 100 max = 110 }
	}
}

# Any scope: moves the setting $var$ (+ 100) one $step$ in the direction of the flag scope:pp_dir (up / down), kept
# between $min$ and $max$ (both + 100). $current$ is the setting's value with its default.
pp_cplan_step_var = {
	set_variable = { name = $var$ value = { value = $current$ add = 100 } }
	if = {
		limit = { scope:pp_dir = flag:up }
		change_variable = { name = $var$ add = $step$ }
	}
	else = {
		change_variable = { name = $var$ subtract = $step$ }
	}
	if = {
		limit = { var:$var$ < $min$ }
		set_variable = { name = $var$ value = $min$ }
	}
	if = {
		limit = { var:$var$ > $max$ }
		set_variable = { name = $var$ value = $max$ }
	}
}
