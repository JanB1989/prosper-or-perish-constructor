# Prosper or Perish - the plan engine of the Construction Plan's Locations group (rule group "profiles", construction
# code 105, its own purse). Location Profiles and the Location Plan's building marks are gone (2026-11-19, Jan): the one
# per-location decision is the plan, a town right pp_plan_<plan> (town_plans.py, scripted_effects/pp_location_plan.txt).
# The script names keep their old prefixes (pp_lprof_*, pp_lplan_*).
# A location that holds a plan gets its turn in the group's looks; in it every held plan runs its target (the plan's
# producers, generated pp_lprof_t_<target> in pp_location_profiles_generated.txt, location_profiles.py), FORCED (Jan
# 2026-11-10: "this location-specific upgrading should just force the upgrades ... sometimes I might want to invest in
# stuff that's zero profit or buildings that don't even have a profit gate, for example a marketplace"): no payback
# limit and no market limit (scope:pp_cplan_forced); it still needs the can-build check, the workers, the construction
# goods, a free construction slot and the group's purse. Inside one location the plans take turns (pp_lplan_last), or
# with the setting "best payback first" the plans whose next level has a profit to measure go first, the best payback
# first, then the rest in the plans' order (pp_lplan_location_turn). A plan keeps its state (pp_lplan_st_g_<plan>,
# pp_lplan_est_g_<plan>). Plans add: they switch nothing off in the global rule groups.
# Plan settings (2026-11-20, Jan; country variables, town_plans.py "Plan settings", the settings tab): a payback limit
# for every plan and for each plan (pp_tplan_pb_all / pp_tplan_pb_<plan>, default any payback: forced as above), never
# a level to a building that loses money at full staffing (default; pp_tplan_loss_ok switches it off), wait for free
# workers (default; pp_tplan_staff_off), take turns (default; pp_tplan_order_best = best payback first).
# The locations take turns (Jan 2026-11-10; until then the fewest building levels went first, so the same places always
# did): every location gets a number when it first joins a look (pp_lprof_seq, counted on the country as
# pp_lprof_seq_n, both + 100), a look starts after the country's place in that order (pp_lprof_cursor) and wraps
# around; the place then moves to just before the location the group saves for, and past it once that is built.
# Player-only like the plan: the pass runs for human countries that switched the plan on.
# Variables carry + 100 (a variable at 0 counts as unset; var:x = n compares scopes, so numbers use < / > ranges).
#
# Location: pp_lplan_st_g_<plan> (the plan's state after the last pass: 1 started, 2 nothing to build, 3 a level under
# construction, 4 no free workers, 5 the next level pays back too slowly for the plan's payback limit, 6 cannot be built
# here, 7 gold (the group's purse cannot pay it, or the group saves for something before it), 8 the market lacks the
# construction goods, 9 waiting for an earlier plan's construction this month, 11 needs a higher rank that cannot be
# raised here now, 12 the standing building loses money at full staffing, 13 the standing building is closed, 14
# another business here is being closed to free workers for it (pp_plan_closer.txt); 10 is the market limit, which no
# plan has), pp_lplan_est_g_<plan> (the payback found), pp_lprof_seq (its number in the turn
# order), pp_lplan_last (the n of the plan that started the last construction here: the plans take turns),
# pp_lplan_wk (yes: one of its plans ended its last turn
# waiting for workers, state 4 or 14; the other rule groups read it), pp_lprof_pos (its place in the running look,
# + 100). Country, while a look's daily slices run: the list pp_lprof_todo
# (the look's locations in turn order), pp_lprof_todo_n / pp_lprof_done (their number / those walked, + 100),
# pp_lprof_k (locations a slice), pp_lprof_pend (yes: slices are left). Pass temporaries:
# pp_lprof_st, pp_lprof_fail, pp_lprof_best, pp_lprof_pick and what the pick carries (pp_lprof_pick_ipl / _pf / _ef /
# _room), the measuring's pp_lplan_b* (location), the list pp_lprof_turns (country: this look's locations, gathered),
# scope:pp_lprof_costing (1 in a costing turn).
# Daily slices (2026-11-20, tested in game the same day, docs/location_plan.md): a look orders all its locations at once (pp_lprof_todo) and walks K of
# them a day, K = max(look_slice_min, ceil(locations / look_slice_days)) ([construction_plan], 60 and 24): the first K
# on the look's day inside the pass, the rest one hidden event a day (events/pp_construction_plan_events.txt,
# pp_lprof_slice_event). A look that walked thousands of plans in one day froze the game (about 0.47 ms a location).
# The purse rule is unchanged (turn order; the first thing it cannot pay is what the group saves for; after that
# nothing starts), but the walk goes on: a turn that begins while the group already saves is a costing turn
# (scope:pp_lprof_costing): the plans run, so their states are set and their wanted gold is counted for the window,
# and nothing else happens there: nothing starts, no business is closed, the closer's wait does not count down, and
# the location's mark pp_lplan_wk is neither set nor removed.
# Script time (2026-11-20): the candidates know their building type when the script is written, so they check its room
# under the max level by its own value and build through pp_lprof_build_known (no dispatch over every building type);
# only the measured best plan (setting "best payback first") goes through the generic pp_lprof_build.

# ---- The monthly pass (country scope, inside pp_cplan_run: scope:pp_cplan_country and scope:actor saved) ----

pp_lprof_run = {
	# plans free their workers (pp_plan_closer.txt, 2026-11-20): the widget's lists emptied, the closings checked
	pp_pclose_month = yes
	# a look's daily slices end within look_slice_days (< 28): anything still pending from an earlier look goes
	if = {
		limit = { has_variable = pp_lprof_pend }
		pp_lprof_drop = yes
	}
	if = {
		limit = {
			pp_lprof_has_locations = yes
			pp_cplan_profiles_w > 0
		}
		# script time (2026-11-10): the group looks at its locations only in its months ([construction_plan]
		# look_months, pp_cplan_looks_profiles); between its looks it only goes back to the location it saves for,
		# once its purse can pay (pp_cplan_group_target)
		if = {
			limit = { pp_cplan_looks_profiles = yes }
			pp_lprof_look = yes
		}
		else = {
			pp_cplan_group_target = { why = 105 do = pp_lprof_target_turn }
		}
	}
	remove_variable = pp_cplan_hit
	remove_variable = pp_cplan_noted
	# Never runs: the flags the plan settings' buttons pass (scope:pp_key, town_plans.py) exist for the script check
	if = {
		limit = { always = no }
		pp_tplan_settings_declare = yes
		remove_variable = pp_tplan_sflag
		pp_pclose_declare = yes
	}
}

# Country scope: the cache pp_lprof_any (yes: a location of the country holds a plan; pp_lprof_group_n reads it, the
# window's rows read that about a hundred times a frame) from the real test, once: at every pass's start before the
# purses move (pp_cplan_pass_begin), when the plan is switched on (pp_cplan_toggle_on) and when a location's last plan
# is taken off (pp_tplan_flip; setting a plan sets it at once). A plan lost by conquest is caught by the next pass.
# The test as pp_lprof_has_locations, with this country instead of root (the flip's root is a location).
pp_lprof_any_refresh = {
	save_temporary_scope_as = pp_lprof_c
	if = {
		limit = {
			any_locations_with_town_rights_in_country = {
				owner ?= scope:pp_lprof_c
				pp_tplan_held = yes
			}
		}
		set_variable = { name = pp_lprof_any value = yes }
	}
	else = {
		remove_variable = pp_lprof_any
	}
}

# Country scope: the Locations group's look: every location that holds a plan, in turns, in daily slices.
pp_lprof_look = {
	pp_cplan_group_start = { why = 105 }
	save_temporary_scope_value_as = { name = pp_cplan_rv value = 0 }
	if = {
		limit = { NOT = { has_variable = pp_lprof_seq_n } }
		set_variable = { name = pp_lprof_seq_n value = 100 }
	}
	if = {
		limit = { NOT = { has_variable = pp_lprof_cursor } }
		set_variable = { name = pp_lprof_cursor value = 100 }
	}
	# what an earlier look left (none: its slices end within look_slice_days)
	pp_lprof_drop = yes
	# this look's locations: those that hold a plan (a new one gets its number)
	pp_lprof_gather = yes
	# the locations take turns (Jan 2026-11-10): the look starts after the country's place in the order of the
	# locations' numbers and wraps around (pp_lprof_turn). In the list's own order the locations assigned first took
	# the whole monthly share every month (test world, 2026-11-08); fewest building levels first, the order until
	# 2026-11-10, always served the same places first.
	# Daily slices (2026-11-20): the order is fixed once, here: every location of the look goes onto pp_lprof_todo with
	# its place (pp_lprof_pos, + 100); the slices walk the places in order (pp_lprof_slice). The window counts the
	# look's locations (pp_cplan_ds_profiles_locs) and those still to be checked (pp_cplan_ds_profiles_unr).
	save_temporary_scope_value_as = { name = pp_lprof_cur value = var:pp_lprof_cursor }
	set_variable = { name = pp_lprof_todo_n value = 100 }
	set_variable = { name = pp_lprof_done value = 100 }
	ordered_in_list = {
		variable = pp_lprof_turns
		order_by = pp_lprof_turn
		max = 100000
		check_range_bounds = no
		save_temporary_scope_as = pp_lprof_this
		scope:pp_cplan_country = {
			change_variable = { name = pp_lprof_todo_n add = 1 }
			change_variable = { name = pp_cplan_ds_profiles_locs add = 1 }
			add_to_variable_list = { name = pp_lprof_todo target = scope:pp_lprof_this }
		}
		set_variable = { name = pp_lprof_pos value = scope:pp_cplan_country.var:pp_lprof_todo_n }
	}
	clear_variable_list = pp_lprof_turns
	set_variable = { name = pp_cplan_ds_profiles_unr value = var:pp_lprof_todo_n }
	# K locations a slice; the console's whole look (pp_cplan_test_profiles, pp_lprof_whole) takes them all at once
	set_variable = { name = pp_lprof_k value = pp_lprof_slice_k }
	if = {
		limit = { has_variable = pp_lprof_whole }
		set_variable = { name = pp_lprof_k value = { value = var:pp_lprof_todo_n subtract = 100 min = 1 } }
	}
	set_variable = { name = pp_lprof_pend value = yes }
	# the first slice at once, in the pass
	pp_lprof_slice = yes
	remove_variable = pp_cplan_hit
	remove_variable = pp_cplan_noted
}

# Country scope (a look's slices pending; scope:pp_cplan_country, scope:actor and the pass temporaries set): the next
# pp_lprof_k places of pp_lprof_todo, in turn order. Each location still owned that still holds a plan gets its turn
# (pp_lprof_slice_turn). Then: the look is done (pp_lprof_look_end), or the next slice comes a day later (a hidden
# event, pp_construction_plan.1 -> pp_lprof_slice_event). The purse rule needs nothing of its own here: the first thing
# the purse cannot pay sets pp_cplan_save_cost_105 (pp_cplan_note_wait, the rank raise's wait), and every turn that
# begins after it, in this slice or a later one, is a costing turn (pp_lprof_location_turn).
pp_lprof_slice = {
	save_temporary_scope_value_as = { name = pp_lprof_from value = var:pp_lprof_done }
	save_temporary_scope_value_as = { name = pp_lprof_to value = { value = var:pp_lprof_done add = var:pp_lprof_k } }
	ordered_in_list = {
		variable = pp_lprof_todo
		limit = {
			has_variable = pp_lprof_pos
			var:pp_lprof_pos > scope:pp_lprof_from
			var:pp_lprof_pos <= scope:pp_lprof_to
		}
		order_by = pp_lprof_pos_order
		max = 100000
		check_range_bounds = no
		pp_lprof_slice_turn = yes
	}
	set_variable = { name = pp_lprof_done value = scope:pp_lprof_to }
	if = {
		limit = { var:pp_lprof_done > var:pp_lprof_todo_n }
		set_variable = { name = pp_lprof_done value = var:pp_lprof_todo_n }
	}
	# the window: the locations of this look still to be checked (+ 100)
	set_variable = { name = pp_cplan_ds_profiles_unr value = { value = var:pp_lprof_todo_n subtract = var:pp_lprof_done add = 100 } }
	if = {
		limit = { var:pp_lprof_done >= var:pp_lprof_todo_n }
		pp_lprof_look_end = yes
	}
	else = {
		trigger_event_silently = { id = pp_construction_plan.1 days = 1 }
	}
}

# Location scope, a place of a look's slice: its turn, when the country still owns it and it still holds a plan (an
# owner change or a plan taken off since the look began drops it).
pp_lprof_slice_turn = {
	if = {
		limit = {
			owner ?= scope:pp_cplan_country
			pp_tplan_held = yes
		}
		pp_lprof_location_turn = yes
	}
}

# Country scope: the look's last slice ran. The place in the turn order moves to just before the location the group
# now saves for (the first thing in turn order its purse could not pay): the next look starts there again; once it is
# built the place moves past it (pp_lprof_target_turn). A look that could pay for everything leaves the place where it
# was. The look's list goes, and its situation goes into the window's history by look (pp_cplan_hq_push_105).
pp_lprof_look_end = {
	save_temporary_scope_value_as = { name = pp_lprof_cur value = var:pp_lprof_cursor }
	if = {
		limit = { has_variable = pp_cplan_save_loc_105 }
		var:pp_cplan_save_loc_105 = {
			if = {
				limit = { has_variable = pp_lprof_seq }
				save_temporary_scope_value_as = { name = pp_lprof_cur value = { value = var:pp_lprof_seq subtract = 1 } }
			}
		}
		set_variable = { name = pp_lprof_cursor value = scope:pp_lprof_cur }
	}
	pp_lprof_drop = yes
	pp_cplan_hq_push_105 = yes
}

# Country scope: a look's slices end (done, the plan switched off, the group off, or a new look): the list and its
# numbers go; nothing is left to check.
pp_lprof_drop = {
	every_in_list = {
		variable = pp_lprof_todo
		remove_variable = pp_lprof_pos
	}
	clear_variable_list = pp_lprof_todo
	remove_variable = pp_lprof_todo_n
	remove_variable = pp_lprof_done
	remove_variable = pp_lprof_k
	remove_variable = pp_lprof_pend
	if = {
		limit = { has_variable = pp_cplan_ds_profiles_unr }
		set_variable = { name = pp_cplan_ds_profiles_unr value = 100 }
	}
}

# Country scope, the hidden event pp_construction_plan.1 a day after a slice: the next slice, outside the monthly pass.
# Nothing, and the look's list goes, when the plan is off, the country no longer runs it (the same test as the monthly
# on_action pp_construction_plan_monthly) or the group's weight is 0. Else what a turn reads of a pass is set up as
# pp_cplan_pass_begin does (the scopes, the reason temporaries, forced 0, no construction this turn), without filling a
# purse or resetting a number: the look's counts go on. After the slice the window's chart takes the look's totals as
# its month 1 again (the pass's end wrote it from the first slice; no monthly pass falls between the slices), and once
# the last slice ran the Locations group hands its purse on (pp_cplan_purses_hand_on_105; at the pass's end it waited).
pp_lprof_slice_event = {
	if = {
		limit = {
			has_variable = pp_lprof_pend
			has_variable = pp_cplan_on
			OR = {
				is_ai = no
				has_variable = pp_cplan_ai_test
			}
			pp_cplan_profiles_w > 0
		}
		save_scope_as = pp_cplan_country
		save_scope_as = actor
		save_temporary_scope_value_as = { name = pp_cplan_rv value = 0 }
		save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
		save_temporary_scope_value_as = { name = pp_cplan_forced value = 0 }
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
		pp_lprof_slice = yes
		remove_variable = pp_cplan_hit
		remove_variable = pp_cplan_noted
		remove_variable = pp_cplan_wait
		remove_variable = pp_cplan_mlim
		set_variable = { name = pp_cplan_hn_105_1 value = { value = var:pp_cplan_dspent_105 add = var:pp_cplan_dwait_105 subtract = 100 } }
		set_variable = { name = pp_cplan_hs_105_1 value = var:pp_cplan_dspent_105 }
		if = {
			limit = { NOT = { has_variable = pp_lprof_pend } }
			pp_cplan_purses_hand_on_105 = yes
		}
		# the window's forecast: the look's wanted gold grew (construction_plan_forecast.py)
		pp_cplan_forecast_store = yes
	}
	else = {
		pp_lprof_drop = yes
	}
}

# Location scope (pp_cplan_group_target: where the group saved for something, its purse can pay now): the location's
# turn again; when it built, the country's place in the turn order moves past this location. What the group saved
# for is let go of first (pp_cplan_group_target: the cost and the place; here the town or city upgrade a plan saved
# for, pp_cplan_save_rank_105, as Towns and Buildings' pp_cplan_country_target does for 107): the plan's turn raises
# the rank again where it still needs it (pp_tplan_do_<plan> -> pp_tplan_raise), with every gate of a look, and saves
# for it again when the gold falls short after all.
pp_lprof_target_turn = {
	scope:pp_cplan_country = { remove_variable = pp_cplan_save_rank_105 }
	pp_lprof_location_turn = yes
	if = {
		limit = {
			scope:pp_cplan_country = { has_variable = pp_cplan_hit }
			has_variable = pp_lprof_seq
		}
		save_temporary_scope_value_as = { name = pp_lprof_cur value = var:pp_lprof_seq }
		scope:pp_cplan_country = { set_variable = { name = pp_lprof_cursor value = scope:pp_lprof_cur } }
	}
}

# Location scope (a location that holds a plan; also where the group saved for something): its turn: its plans,
# forced. A turn that begins while the group already saves for something (pp_cplan_save_cost_105) is a costing turn
# (scope:pp_lprof_costing = 1, daily slices 2026-11-20): before them such locations were not walked at all, so only the
# plans' states and the window's counters may change there: nothing can start (pp_cplan_construct_go and
# pp_cplan_country_rank_up start nothing while the group saves), no business is closed (pp_pclose_may and
# pp_lplan_mark), the closer's wait does not count down (pp_pclose_turn_start), and the mark pp_lplan_wk stays as it
# was (here and in pp_lprof_finish).
pp_lprof_location_turn = {
	save_temporary_scope_value_as = { name = pp_lprof_costing value = 0 }
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_save_cost_105 } }
		save_temporary_scope_value_as = { name = pp_lprof_costing value = 1 }
	}
	# a plan waiting for workers here marks the location anew in this turn (pp_lprof_finish)
	if = {
		limit = { scope:pp_lprof_costing < 0.5 }
		remove_variable = pp_lplan_wk
	}
	# the workers a new level can find here (pp_cplan_staff)
	save_temporary_scope_value_as = { name = pp_cplan_free_peasants value = pp_cplan_free_peasants_here }
	# the window: one level waiting for gold counts once a location (pp_cplan_note_wait); one construction a
	# turn in a location (pp_cplan_hit)
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_noted
		remove_variable = pp_cplan_hit
	}
	# plans free their workers (pp_plan_closer.txt): the wait after a closing counts down a look
	pp_pclose_turn_start = yes
	save_temporary_scope_value_as = { name = pp_cplan_forced value = 0 }
	save_temporary_scope_value_as = { name = pp_lplan_mode value = 0 }
	# its plans (town rights pp_plan_<plan>, town_plans.py; 2026-11-19)
	if = {
		limit = { pp_tplan_held = yes }
		pp_lplan_location_turn = yes
	}
	save_temporary_scope_value_as = { name = pp_cplan_forced value = 0 }
	save_temporary_scope_value_as = { name = pp_lplan_mode value = 0 }
	pp_pclose_turn_end = yes
}

# Location scope: the location's plans, forced (scope:pp_cplan_forced = 1: no market limit; scope:pp_lprof_pb far away:
# no payback limit, unless the plan has one: pp_tplan_set_pb in pp_lplan_mark). While a payback limit is set anywhere
# (pp_tplan_pb_some) this year's harvest is taken first: the Businesses estimates of first levels and tier upgrades read
# it. By default the plans take turns (one go, pp_lplan_location_marks_turns: the plans after the one that started the
# location's last construction first). With the setting "best payback first" (pp_tplan_order_best), two goes over the
# plans (scope:pp_lplan_mode):
#   1. measure (only where a construction can start here now): every plan whose next level could be built (the
#      can-build check, not at its highest level, workers, construction goods) and has a profit to measure (a standing
#      building that earns) offers its payback; the best one is built at once, before any other plan (pp_lplan_bt
#      the building type with its cost data pp_lplan_bipl / _bpf / _bef, pp_lplan_bp its payback + 100, pp_lplan_bn the
#      plan's number, pp_lplan_bo what came of it: 101 started, 107 gold, 102 it could not be built after all);
#   2. the plans in their order: the measured one takes its outcome as its state, the others run their targets without
#      a payback limit: after a construction started they wait, a first level (a Marketplace, nothing to measure) or a
#      level without profit is built here.
# The window's ledger shows a plan's construction as the group's, step 0.
pp_lplan_location_turn = {
	save_temporary_scope_value_as = { name = pp_cplan_forced value = 1 }
	save_temporary_scope_value_as = { name = pp_lprof_pb value = 1000000 }
	save_temporary_scope_value_as = { name = pp_cplan_rs value = 0 }
	pp_lplan_measure_clear = yes
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_tplan_pb_some } }
		pp_cplan_business_harvest = yes
	}
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_tplan_order_best } }
		if = {
			limit = {
				scope:pp_cplan_country = { NOT = { has_variable = pp_cplan_hit } }
				pp_cplan_site_free = yes
			}
			save_temporary_scope_value_as = { name = pp_lplan_mode value = 1 }
			pp_lplan_location_marks = yes
			if = {
				limit = { has_variable = pp_lplan_bt }
				var:pp_lplan_bt = { save_scope_as = pp_cplan_btype }
				# the cost data the measured level was priced with (pp_lplan_measure)
				save_temporary_scope_value_as = { name = pp_cplan_ipl value = { value = var:pp_lplan_bipl subtract = 100 } }
				save_temporary_scope_value_as = { name = pp_cplan_pf value = { value = var:pp_lplan_bpf subtract = 100 } }
				save_temporary_scope_value_as = { name = pp_cplan_ef value = { value = var:pp_lplan_bef subtract = 100 } }
				pp_lprof_build = yes
				if = {
					limit = { scope:pp_cplan_country = { has_variable = pp_cplan_hit } }
					set_variable = { name = pp_lplan_bo value = 101 }
				}
				else_if = {
					limit = {
						has_variable = pp_lprof_fail
						var:pp_lprof_fail > 106.5
					}
					set_variable = { name = pp_lplan_bo value = 107 }
				}
				else = {
					set_variable = { name = pp_lplan_bo value = 102 }
				}
				remove_variable = pp_lprof_st
				remove_variable = pp_lprof_fail
				remove_variable = pp_lprof_best
			}
		}
		save_temporary_scope_value_as = { name = pp_lplan_mode value = 2 }
		pp_lplan_location_marks = yes
	}
	else = {
		# the plans take turns (the default): no measuring go; the split between the two goes as the turn begins
		save_temporary_scope_value_as = { name = pp_lplan_mode value = 2 }
		save_temporary_scope_value_as = { name = pp_lplan_from value = 0 }
		if = {
			limit = { has_variable = pp_lplan_last }
			save_temporary_scope_value_as = { name = pp_lplan_from value = var:pp_lplan_last }
		}
		pp_lplan_location_marks_turns = yes
	}
	pp_lplan_measure_clear = yes
}

# Location scope, in a plan's turn: scope:pp_lprof_pb = the payback limit of the plan $g$ in years + 100 (its own
# setting, else the all-plans one, pp_tplan_pb_years_$g$ on the country), or far away when it has none (any payback).
pp_tplan_set_pb = {
	scope:pp_cplan_country = {
		save_temporary_scope_value_as = { name = pp_tplan_pby value = pp_tplan_pb_years_$g$ }
	}
	if = {
		limit = { scope:pp_tplan_pby > 0.5 }
		save_temporary_scope_value_as = { name = pp_lprof_pb value = { value = scope:pp_tplan_pby add = 100 } }
	}
	else = {
		save_temporary_scope_value_as = { name = pp_lprof_pb value = 1000000 }
	}
}

# Location scope (the plans take turns, pp_lplan_location_marks_turns): the plan $g$ runs in the first go
# ($first$ = yes) when it comes after the plan that started the location's last construction (scope:pp_lplan_from,
# pp_lplan_last as it stood when the turn began; 0 when none did: all of them), in the second go when it does not
# (the generated effect skips the second go when none did); the plan is checked held too.
# The split is taken at the turn's start (2026-11-20): read live, a plan that started a construction in the first go
# moved pp_lplan_last, and the plans up to it ran a second time, the starter itself included: no construction (the
# turn's first construction makes every later plan wait), but their states became "waiting" (9) and they were counted
# twice in the window.
pp_lplan_mark_turn = {
	if = {
		limit = {
			OR = {
				AND = {
					always = $first$
					scope:pp_lplan_from < $lo$
				}
				AND = {
					NOT = { always = $first$ }
					scope:pp_lplan_from > $lo$
				}
			}
			has_town_rights = town_rights_type:pp_plan_$g$
		}
		pp_lplan_mark = { v = $v$ g = $g$ do = $do$ n = $n$ lo = $lo$ hi = $hi$ }
	}
}

# Location scope: what the measuring of the plans left here is gone.
pp_lplan_measure_clear = {

	remove_variable = pp_lplan_bt
	remove_variable = pp_lplan_bn
	remove_variable = pp_lplan_bo
	remove_variable = pp_lplan_bq
	remove_variable = pp_lplan_bipl
	remove_variable = pp_lplan_bpf
	remove_variable = pp_lplan_bef
}

# Location scope, while the plans are measured (scope:pp_cplan_btype and its cost data set; the candidate could be
# built here now): its payback becomes the location's best when it has a profit to measure (pp_lprof_payback100 below
# 1099 = no profit) and pays back sooner than the best so far; its cost data is kept beside it (+ 100) for the build.
# The payback is worked out once (three walks over the location's buildings) and kept in scope:pp_lplan_pb100.
pp_lplan_measure = {
	save_temporary_scope_value_as = { name = pp_lplan_pb100 value = pp_lprof_payback100 }
	if = {
		limit = {
			scope:pp_lplan_pb100 < 1098
			OR = {
				NOT = { has_variable = pp_lplan_bp }
				var:pp_lplan_bp > scope:pp_lplan_pb100
			}
		}
		set_variable = { name = pp_lplan_bp value = scope:pp_lplan_pb100 }
		set_variable = { name = pp_lplan_bt value = scope:pp_cplan_btype }
		set_variable = { name = pp_lplan_bipl value = { value = scope:pp_cplan_ipl add = 100 } }
		set_variable = { name = pp_lplan_bpf value = { value = scope:pp_cplan_pf add = 100 } }
		set_variable = { name = pp_lplan_bef value = { value = scope:pp_cplan_ef add = 100 } }
	}
}

# Location scope, while the plans are measured: before a plan measures, the best payback so far is kept
# (pp_lplan_bq); after it, the plan $n$ is the best when it lowered it. What the measuring left of the temporaries
# goes.
pp_lplan_measure_before = {
	pp_cplan_copy_num = { from = pp_lplan_bp to = pp_lplan_bq }
}
pp_lplan_measure_after = {
	if = {
		limit = {
			has_variable = pp_lplan_bp
			OR = {
				NOT = { has_variable = pp_lplan_bq }
				var:pp_lplan_bq > var:pp_lplan_bp
			}
		}
		set_variable = { name = pp_lplan_bn value = $n$ }
	}
	remove_variable = pp_lplan_bq
	remove_variable = pp_lprof_st
	remove_variable = pp_lprof_fail
	remove_variable = pp_lprof_best
	pp_lprof_pick_clear = yes
}

# Country scope: the list pp_lprof_turns = the country's locations that hold a plan right (town_plans.py, 2026-11-19:
# found among the country's locations with town rights, no list of their own), each once.
pp_lprof_gather = {
	clear_variable_list = pp_lprof_turns
	every_locations_with_town_rights_in_country = {
		limit = {
			owner ?= scope:pp_cplan_country
			pp_tplan_held = yes
		}
		pp_lprof_take_turn = yes
	}
}

# Location scope: joins this pass's locations; one that never did gets the next number of the turn order.
pp_lprof_take_turn = {
	save_temporary_scope_as = pp_lprof_this
	if = {
		limit = { NOT = { has_variable = pp_lprof_seq } }
		scope:pp_cplan_country = { change_variable = { name = pp_lprof_seq_n add = 1 } }
		set_variable = { name = pp_lprof_seq value = scope:pp_cplan_country.var:pp_lprof_seq_n }
	}
	scope:pp_cplan_country = { add_to_variable_list = { name = pp_lprof_turns target = scope:pp_lprof_this } }
}

# Location scope: the plan $g$ (town_plans.py, 2026-11-19: the town right pp_plan_$g$), when the location holds it:
# "build this here", forced. $do$ is the plan's generated target effect (pp_lprof_t_<target>, or pp_tplan_do_$g$ where
# it raises the rank first), with no payback limit (scope:pp_lprof_pb, pp_lplan_location_turn). $n$ is the plan's
# number in the plans' order (+ 100), $lo$ / $hi$ the bounds around it. While the plans are measured
# (scope:pp_lplan_mode 1) the target only offers its best payback (pp_lprof_expand) and the plan notes when it is the
# location's best (pp_lplan_bn = $n$). In the second go the measured plan takes what came of its construction as its
# state (pp_lplan_bo), every other plan runs its target. The state goes into pp_lplan_st_$v$ ($v$ = g_$g$), the
# payback found into pp_lplan_est_$v$.
pp_lplan_mark = {
	if = {
		limit = { has_town_rights = town_rights_type:pp_plan_$g$ }
		# the plan's payback limit (plan settings; none = forced)
		pp_tplan_set_pb = { g = $g$ }
		if = {
			limit = { pp_lplan_measuring = yes }
			pp_lplan_measure_before = yes
			$do$ = yes
			pp_lplan_measure_after = { n = $n$ }
		}
		else = {
			pp_lprof_open = yes
			if = {
				limit = {
					has_variable = pp_lplan_bo
					has_variable = pp_lplan_bn
					var:pp_lplan_bn > $lo$
					var:pp_lplan_bn < $hi$
				}
				remove_variable = pp_lprof_st
				if = {
					limit = { var:pp_lplan_bo < 101.5 }
					set_variable = { name = pp_lprof_st value = 101 }
				}
				else_if = {
					limit = { var:pp_lplan_bo > 106.5 }
					pp_lprof_fail = { r = 107 }
				}
				else = {
					pp_lprof_fail = { r = 102 }
				}
			}
			else_if = {
				limit = { NOT = { has_variable = pp_lprof_st } }
				$do$ = yes
				# it started a construction: the next look begins with the plans after it (the plans take turns)
				if = {
					limit = {
						has_variable = pp_lprof_st
						var:pp_lprof_st < 101.5
					}
					set_variable = { name = pp_lplan_last value = $n$ }
				}
				# its level waits for workers and nothing else: another business here closes for them
				# (pp_plan_closer.txt; state 14 while that is under way, else 4). Never in a costing turn
				# (pp_lprof_location_turn): pp_pclose_may already refuses while the group saves; here a plan the
				# closing under way is for (pp_pclose_for) still reads 14, without touching the closer
				if = {
					limit = {
						scope:pp_lprof_costing < 0.5
						NOT = { has_variable = pp_lprof_st }
						has_variable = pp_lprof_fail
						var:pp_lprof_fail > 104.125
						var:pp_lprof_fail < 104.625
					}
					pp_pclose_plan = { g = $g$ }
				}
				else_if = {
					limit = {
						scope:pp_lprof_costing > 0.5
						NOT = { has_variable = pp_lprof_st }
						has_variable = pp_lprof_fail
						var:pp_lprof_fail > 103.75
						var:pp_lprof_fail < 104.625
						has_variable = pp_pclose_wait
						is_target_in_variable_list = { name = pp_pclose_for target = town_rights_type:pp_plan_$g$ }
					}
					set_variable = { name = pp_lprof_fail value = 104.25 }
				}
				else_if = {
					limit = {
						scope:pp_lprof_costing > 0.5
						has_variable = pp_lprof_fail
						var:pp_lprof_fail > 104.125
						var:pp_lprof_fail < 104.625
					}
					set_variable = { name = pp_lprof_fail value = 104 }
				}
			}
			pp_lprof_finish = { st = pp_lplan_st_$v$ est = pp_lplan_est_$v$ }
		}
	}
}

# Location scope: a plan starts afresh. Nothing can start here now: after a construction started here this month by
# an earlier plan it waits (pp_lprof_st 109), and while a construction is under way here too (103: one at a time in a
# location, the plan's own check pp_cplan_site_free). pp_lprof_st stays unset when it may try.
pp_lprof_open = {
	remove_variable = pp_lprof_st
	remove_variable = pp_lprof_fail
	remove_variable = pp_lprof_best
	remove_variable = pp_pclose_pt
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_hit } }
		set_variable = { name = pp_lprof_st value = 109 }
	}
	else_if = {
		limit = { NOT = { pp_cplan_site_free = yes } }
		set_variable = { name = pp_lprof_st value = 103 }
	}
}

# Location scope: writes the state of a plan into $st$: what the target set (1 started, 3 a level under construction,
# 9 waiting), else the best reason among its candidates (pp_lprof_fail: 108 a plan needs a higher rank that cannot be
# raised here now -> 11, 107 gold -> 7, 106 the market limit -> 10, 105 goods -> 8, 104.25 workers and nothing else
# while another business here closes for them (pp_pclose_plan) -> 14, 104 no workers -> 4, 103.5 the
# standing building loses money -> 12, 103 payback -> 5, 102.5 the standing building is closed -> 13, 102 cannot be
# built -> 6, 101 at its highest level -> 2; the half ranks split at the midpoints), else no candidate at all (6); and
# into $est$ the shortest payback it found.
pp_lprof_finish = {
	if = {
		limit = { has_variable = pp_lprof_st }
		set_variable = { name = $st$ value = var:pp_lprof_st }
	}
	else_if = {
		limit = { NOT = { has_variable = pp_lprof_fail } }
		set_variable = { name = $st$ value = 106 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 107.5 }
		set_variable = { name = $st$ value = 111 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 106.5 }
		set_variable = { name = $st$ value = 107 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 105.5 }
		set_variable = { name = $st$ value = 110 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 104.625 }
		set_variable = { name = $st$ value = 108 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 104.125 }
		set_variable = { name = $st$ value = 114 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 103.75 }
		set_variable = { name = $st$ value = 104 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 103.25 }
		set_variable = { name = $st$ value = 112 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 102.75 }
		set_variable = { name = $st$ value = 105 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 102.25 }
		set_variable = { name = $st$ value = 113 }
	}
	else_if = {
		limit = { var:pp_lprof_fail > 101.5 }
		set_variable = { name = $st$ value = 106 }
	}
	else = {
		set_variable = { name = $st$ value = 102 }
	}
	# a plan here waits for workers (4, or 14 while another business closes for it): the location carries pp_lplan_wk
	# for the other rule groups until its next turn (pp_lprof_location_turn; the Businesses rule leaves such a location
	# to its plans); not in a costing turn (pp_lprof_location_turn): the mark stays as the location's last real turn
	# left it
	if = {
		limit = {
			scope:pp_lprof_costing < 0.5
			OR = {
				AND = {
					var:$st$ > 103.5
					var:$st$ < 104.5
				}
				AND = {
					var:$st$ > 113.5
					var:$st$ < 114.5
				}
			}
		}
		set_variable = { name = pp_lplan_wk value = yes }
	}
	# the shortest payback of a standing candidate's next level (years + 100; 1099 = no profit), shown beside the state
	if = {
		limit = { has_variable = pp_lprof_best }
		set_variable = { name = $est$ value = var:pp_lprof_best }
	}
	else = {
		remove_variable = $est$
	}
	remove_variable = pp_lprof_st
	remove_variable = pp_lprof_fail
	remove_variable = pp_lprof_best
	# the window counts the states at a look only (not when the group goes back to one location between looks)
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_now_105 } }
		pp_lprof_count_state = { st = $st$ }
	}
}

		scope:pp_cplan_country = { change_variable = { name = pp_cplan_ds_profiles_st4 add = 1 } }
	}

		limit = { var:$st$ < 105.5 }
		scope:pp_cplan_country = { change_variable = { name = pp_cplan_ds_profiles_st5 add = 1 } }
	}
	else_if = {
		limit = { var:$st$ < 106.5 }
		scope:pp_cplan_country = { change_variable = { name = pp_cplan_ds_profiles_st6 add = 1 } }
	}

# Location scope (scope:pp_cplan_btype and the cost values set): keeps the shortest payback seen for this plan.
pp_lprof_note_payback = {

				var:pp_lprof_best > pp_lprof_payback100
			}

	}
}

# Location scope: records why a candidate failed ($r$ = 101..108; 104.25: workers and nothing else, pp_plan_closer.txt),
# keeping the reason closest to a construction.
pp_lprof_fail = {
	if = {
		limit = { NOT = { has_variable = pp_lprof_fail } }
		set_variable = { name = pp_lprof_fail value = $r$ }
	}
	else_if = {
		limit = { var:pp_lprof_fail < $r$ }
		set_variable = { name = pp_lprof_fail value = $r$ }
	}
}

# Location scope: one more level of the standing $type$ (cost data: increase per level $ipl$, construction demand
# $demand$, efficiency category $cat$; workers: $sz$ of pop type $pt$ a level; $lc$ = yes: it has production methods,
# so it can lose money) when it is below its highest level, open, can be built here, does not lose money at full
# staffing (plan setting, default; the game lays off the workers of such a building every month, subsidised or not:
# building_potential_profit, the profit at full workers and full goods), its next level pays back within
# scope:pp_lprof_pb, finds its workers here (pp_cplan_staff, unless the setting says plans do not wait for them) and
# the market holds its construction goods. Nothing once a construction started.
pp_lprof_expand = {
	if = {
		limit = {
			scope:pp_cplan_country = { NOT = { has_variable = pp_cplan_hit } }
			any_buildings_in_location = { building_type = building_type:$type$ building_level > 0 }
		}
		if = {
			limit = { any_buildings_in_location = { building_type = building_type:$type$ is_at_max_level = yes } }
			pp_lprof_fail = { r = 101 }
		}
		# a closed building gets no level (pp_cplan_construct_scoped refuses it too): its own state
		else_if = {
			limit = { any_buildings_in_location = { building_type = building_type:$type$ is_opened = no } }
			pp_lprof_fail = { r = 102.5 }
		}
		else_if = {
			limit = { NOT = { location_and_owner_can_build = { building_type = $type$ } } }
			pp_lprof_fail = { r = 102 }
		}
		else = {
			building_type:$type$ = { save_scope_as = pp_cplan_btype }
			save_temporary_scope_value_as = { name = pp_cplan_ipl value = $ipl$ }
			save_temporary_scope_value_as = { name = pp_cplan_pf value = pp_cplan_cd_$demand$ }
			save_temporary_scope_value_as = { name = pp_cplan_ef value = pp_cplan_eff_$cat$ }
			pp_lprof_note_payback = yes
			if = {
				limit = {
					always = $lc$
					scope:pp_cplan_country = { NOT = { has_variable = pp_tplan_loss_ok } }
					any_buildings_in_location = {
						building_type = building_type:$type$
						building_potential_profit < 0
					}
				}
				pp_lprof_fail = { r = 103.5 }
			}
			else_if = {
				limit = { pp_lprof_payback100 > scope:pp_lprof_pb }
				pp_lprof_fail = { r = 103 }
			}
			else_if = {
				limit = {
					scope:pp_cplan_country = { NOT = { has_variable = pp_tplan_staff_off } }
					NOT = { pp_cplan_staff = { type = $pt$ size = $sz$ } }
				}
				# 104, or 104.25 when it waits for workers and nothing else (pp_plan_closer.txt)
				pp_pclose_worker_fail = { type = $type$ demand = $demand$ pt = $pt$ }
			}
			else_if = {
				limit = { NOT = { pp_cplan_goods_here_$demand$ = yes } }
				pp_lprof_fail = { r = 105 }
			}
			# a location's plans being measured: the level could be built; it only offers its payback
			else_if = {
				limit = { pp_lplan_measuring = yes }
				pp_lplan_measure = yes
			}
			else = {
				save_temporary_scope_value_as = { name = pp_lprof_room value = pp_cplan_room_$type$ }
				pp_lprof_build_known = yes
			}
		}
	}
}

# Location scope (a target's tier step, town_plans.py 2026-11-19: a plan follows the tiers as they unlock): a standing,
# open level of the older tier $old$ the country can upgrade (pp_cplan_country_upgradable: its successor is
# researched) becomes one of $type$ (the successor, one of the same target's buildings), when the country's part of the
# can-build check passes for it and the market holds its construction goods. A construction of the successor where
# the older tier stands IS the game's Upgrade button (in game 2026-11-10); it asks no workers and not the location's
# part of the can-build check (that is what refuses a new level of an obsolete tier). Under a payback limit the
# successor's level must pay back within it by the Businesses rule's estimate ($est$, where it has one, $hasest$;
# pp_lprof_new_check). Nothing once a construction started or while a location's plans are measured (an upgrade has
# no profit to measure). The "never at a loss" setting does not apply: the upgrade replaces the building.
pp_lprof_upgrade = {
	if = {
		limit = {
			scope:pp_cplan_country = { NOT = { has_variable = pp_cplan_hit } }
			NOT = { pp_lplan_measuring = yes }
			any_buildings_in_location = {
				building_type = building_type:$old$
				pp_cplan_country_upgradable = yes
			}
			scope:pp_cplan_country = { can_build_building = building_type:$type$ }
		}
		if = {
			limit = { NOT = { pp_cplan_goods_here_$demand$ = yes } }
			pp_lprof_fail = { r = 105 }
		}
		else = {
			building_type:$type$ = { save_scope_as = pp_cplan_btype }
			save_temporary_scope_value_as = { name = pp_cplan_ipl value = $ipl$ }
			save_temporary_scope_value_as = { name = pp_cplan_pf value = pp_cplan_cd_$demand$ }
			save_temporary_scope_value_as = { name = pp_cplan_ef value = pp_cplan_eff_$cat$ }
			pp_lprof_new_check = { est = $est$ hasest = $hasest$ }
			if = {
				limit = { scope:pp_lprof_over > 0.5 }
				pp_lprof_fail = { r = 103 }
			}
			else = {
				save_temporary_scope_value_as = { name = pp_lprof_room value = pp_cplan_room_$type$ }
				pp_lprof_build_known = yes
			}
		}
	}
}

# Location scope (none of the target's buildings stands here, or every standing one is at its highest level:
# pp_lprof_more): $type$ joins the start candidates when it can be built here, finds its workers here (unless the
# setting says plans do not wait for them), the market holds its construction goods and, under a payback limit, its
# first level pays back within it by the Businesses rule's estimate (where it has one: pp_lprof_new_check; without one,
# such as a Marketplace, a first level has nothing to measure and is not checked); pp_lprof_start_pick starts the pick
# (nothing while a location's plans are measured). $how$ = the pick rule: cost (the cheapest, pp_lprof_consider_cost)
# or roi (the food plan's farms: the best return here by the food rule's own measure, pp_lprof_consider_roi); the trade
# plan's order (the first that can start) is the generated target's: a later candidate is not tried once a pick stands.
pp_lprof_start = {
	if = {
		limit = { pp_lplan_measuring = yes }
		pp_lprof_pick_clear = yes
	}
	else_if = {
		limit = { location_and_owner_can_build = { building_type = $type$ } }
		if = {
			limit = {
				scope:pp_cplan_country = { NOT = { has_variable = pp_tplan_staff_off } }
				NOT = { pp_cplan_staff = { type = $pt$ size = $sz$ } }
			}
			# 104, or 104.25 when it waits for workers and nothing else (pp_plan_closer.txt)
			pp_pclose_worker_fail_new = { type = $type$ demand = $demand$ pt = $pt$ ipl = $ipl$ cat = $cat$ }
		}
		else_if = {
			limit = { NOT = { pp_cplan_goods_here_$demand$ = yes } }
			pp_lprof_fail = { r = 105 }
		}
		else = {
			building_type:$type$ = { save_scope_as = pp_cplan_btype }
			save_temporary_scope_value_as = { name = pp_cplan_ipl value = $ipl$ }
			save_temporary_scope_value_as = { name = pp_cplan_pf value = pp_cplan_cd_$demand$ }
			save_temporary_scope_value_as = { name = pp_cplan_ef value = pp_cplan_eff_$cat$ }
			pp_lprof_new_check = { est = $est$ hasest = $hasest$ }
			if = {
				limit = { scope:pp_lprof_over > 0.5 }
				pp_lprof_fail = { r = 103 }
			}
			else = {
				pp_lprof_consider_$how$ = { type = $type$ }
			}
		}
	}
	else = {
		pp_lprof_fail = { r = 102 }
	}
}

# Location scope (scope:pp_cplan_btype and its cost values set): scope:pp_lprof_over = 1 when the plan has a payback
# limit (scope:pp_lprof_pb) and the level's payback by the Businesses rule's monthly profit estimate $est$
# (pp_cplan_bz_est_<type>; $hasest$ = no: none) is longer (pp_lprof_new_payback100: no profit counts as too long).
# Without a limit nothing is worked out (the estimate needs this year's harvest, pp_lplan_location_turn).
pp_lprof_new_check = {
	save_temporary_scope_value_as = { name = pp_lprof_over value = 0 }
	if = {
		limit = {
			always = $hasest$
			scope:pp_lprof_pb < 999999
		}
		save_temporary_scope_value_as = { name = pp_lprof_newp value = $est$ }
		if = {
			limit = { pp_lprof_new_payback100 > scope:pp_lprof_pb }
			save_temporary_scope_value_as = { name = pp_lprof_over value = 1 }
		}
	}
}

# Location scope: scope:pp_cplan_btype ($type$) becomes the pick when it costs less than the pick so far
# (pp_lprof_best = 1 + its cost). The pick carries what its build needs (script time 2026-11-20: the build then skips
# the two dispatches over every building type): its cost data (+ 100, a variable at 0 counts as unset) and whether a
# level fits under its max level here (pp_lprof_pick_room; nothing is built between the pick and its start, so the
# room stays what it was).
pp_lprof_consider_cost = {
	save_temporary_scope_value_as = { name = pp_lprof_key value = pp_lprof_cost1 }
	if = {
		limit = {
			OR = {
				NOT = { has_variable = pp_lprof_best }
				var:pp_lprof_best > scope:pp_lprof_key
			}
		}
		pp_lprof_keep = { type = $type$ }
	}
}
# Location scope (the food plan's farms, 2026-11-20): $type$ becomes the pick when it suits the location better than
# the pick so far: the food rule's own measure, the yearly return of a level here at the market's prices and the
# location's output, in % of its base price (pp_cplan_farm_roi_<type>, the same the food rule ranks its farm lines
# by); pp_lprof_best = that + 10000 (never 0, which is unset; a losing farm still ranks below an earning one).
pp_lprof_consider_roi = {
	save_temporary_scope_value_as = { name = pp_lprof_key value = { value = pp_cplan_farm_roi_$type$ add = 10000 } }
	if = {
		limit = {
			OR = {
				NOT = { has_variable = pp_lprof_best }
				var:pp_lprof_best < scope:pp_lprof_key
			}
		}
		pp_lprof_keep = { type = $type$ }
	}
}
# scope:pp_lprof_key = the pick's key (pp_lprof_consider_cost / _roi).
pp_lprof_keep = {
	set_variable = { name = pp_lprof_best value = scope:pp_lprof_key }
	set_variable = { name = pp_lprof_pick value = scope:pp_cplan_btype }
	set_variable = { name = pp_lprof_pick_ipl value = { value = scope:pp_cplan_ipl add = 100 } }
	set_variable = { name = pp_lprof_pick_pf value = { value = scope:pp_cplan_pf add = 100 } }
	set_variable = { name = pp_lprof_pick_ef value = { value = scope:pp_cplan_ef add = 100 } }
	if = {
		limit = { pp_cplan_room_$type$ >= 1 }
		set_variable = { name = pp_lprof_pick_room value = yes }
	}
	else = {
		remove_variable = pp_lprof_pick_room
	}
}

# Location scope: starts the picked building, if any, with the cost data and the room it was picked with
# (pp_lprof_build_known).
pp_lprof_start_pick = {
	if = {
		limit = { has_variable = pp_lprof_pick }
		var:pp_lprof_pick = { save_scope_as = pp_cplan_btype }
		save_temporary_scope_value_as = { name = pp_cplan_ipl value = { value = var:pp_lprof_pick_ipl subtract = 100 } }
		save_temporary_scope_value_as = { name = pp_cplan_pf value = { value = var:pp_lprof_pick_pf subtract = 100 } }
		save_temporary_scope_value_as = { name = pp_cplan_ef value = { value = var:pp_lprof_pick_ef subtract = 100 } }
		save_temporary_scope_value_as = { name = pp_lprof_room value = 0 }
		if = {
			limit = { has_variable = pp_lprof_pick_room }
			save_temporary_scope_value_as = { name = pp_lprof_room value = 1 }
		}
		pp_lprof_build_known = yes
	}
	pp_lprof_pick_clear = yes
	remove_variable = pp_lprof_best
}

# Location scope: the start pick and what it carries are gone.
pp_lprof_pick_clear = {
	remove_variable = pp_lprof_pick
	remove_variable = pp_lprof_pick_ipl
	remove_variable = pp_lprof_pick_pf
	remove_variable = pp_lprof_pick_ef
	remove_variable = pp_lprof_pick_room
}

# Location scope, in a target's turn (2026-11-20, Jan: plans behave sensibly by default): every standing building of
# the target is at its highest level and nothing else stopped them (pp_lprof_fail exactly 101, no construction, not
# measuring), so another of its buildings starts (the generated target's start phase, without the ones standing here
# and their older tiers). The plan's state is then the start phase's reason (workers, gold, goods, ...); where nothing
# could start (none can be built here, or none is left) it stays "nothing to build" (pp_lprof_more_end).
pp_lprof_more = {
	remove_variable = pp_lprof_fail
	remove_variable = pp_lprof_best
	pp_lprof_pick_clear = yes
}
pp_lprof_more_end = {
	if = {
		limit = {
			NOT = { has_variable = pp_lprof_st }
			OR = {
				NOT = { has_variable = pp_lprof_fail }
				var:pp_lprof_fail < 102.25
			}
		}
		remove_variable = pp_lprof_fail
		pp_lprof_fail = { r = 101 }
	}
}

# Location scope: one level of scope:pp_cplan_btype, paid from the Locations group's purse (the plan's construct
# records it in the ledger as the group's construction, why 105). A level the purse cannot pay, or any level once the
# group saves for something: gold (107; the plan counts it for the window and keeps the first as what the group saves
# for, pp_cplan_note_wait); one the market limit stops (enough of its good is on the way in the market): 106
# (pp_cplan_note_market; a forced plan never is); one it refuses for another reason (a level under construction, a
# closed building): cannot be built (102).
# This one is for a type held at run time (the measured best plan, pp_lplan_bt): the generic construct path. The
# candidates that know their type when the script is written build through pp_lprof_build_known.
pp_lprof_build = {
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_wait
		remove_variable = pp_cplan_mlim
	}
	pp_cplan_construct_scoped = { why = 105 }
	pp_lprof_build_end = yes
}

# Location scope: pp_lprof_build for a candidate that knows its type (script time 2026-11-20): scope:pp_cplan_btype,
# its cost data (scope:pp_cplan_ipl / _pf / _ef, the values pp_cplan_btype_data finds for it: both from
# construction_plan.py building_costs, a test compares them) and scope:pp_lprof_room (the type's pp_cplan_room_<type>,
# its room under the max level here) are set. No room: nothing starts, and the plan's state is "cannot be built"
# (102), as pp_cplan_construct_scoped's pp_cplan_no_room gave it; else the same construct path without the two
# dispatches over every building type.
pp_lprof_build_known = {
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_wait
		remove_variable = pp_cplan_mlim
	}
	if = {
		limit = { scope:pp_lprof_room >= 1 }
		pp_cplan_construct_room = { why = 105 data = no }
	}
	pp_lprof_build_end = yes
}

# Location scope, after a plan's construct: the outcome as the plan's reason (started, gold, market limit, cannot).
pp_lprof_build_end = {
	if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_hit } }
		set_variable = { name = pp_lprof_st value = 101 }
	}
	else_if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_wait } }
		pp_lprof_fail = { r = 107 }
	}
	else_if = {
		limit = { scope:pp_cplan_country = { has_variable = pp_cplan_mlim } }
		pp_lprof_fail = { r = 106 }
	}
	else = {
		pp_lprof_fail = { r = 102 }
	}
	scope:pp_cplan_country = {
		remove_variable = pp_cplan_wait
		remove_variable = pp_cplan_mlim
	}
}
